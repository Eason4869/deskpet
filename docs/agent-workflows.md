# 工作、互动与工具使用

本文对应 Windows 0.9.1，介绍聊天、工作权限、统一窗口与工具标签的实际使用。历史标签保留此前快照；正式安装包请以 Releases 页面为准。

## 主窗口、设置与统计

最左列的首页、用量统计、插件拼图、设置齿轮和左下伙伴头像始终可见，当前页面图标采用黑色实心。新打开完整对话默认展开项目／对话侧栏，默认尺寸1280×860逻辑像素并适配屏幕。设置在主窗口中作为完整页面打开，返回／前进可恢复原页面；聊天会话、草稿、阅读位置、运行工具及未保存的设置保持原实例。Ctrl + Shift + S 只收起项目／对话侧栏，窄窗口可临时展开并按 Escape 收起。工具区的分屏／完整视图切换与显示／隐藏是两个独立操作，隐藏不会关闭标签或终端进程。

点击左侧用量图标或左下头像 → 用量统计，进入设置之外的同级页面。概览点阵支持每天、每周和累计，鼠标悬停或键盘聚焦显示日期范围与 Token 详情；分析页有 7／30 天图表、筛选和会话排行。账本按新发生的文字请求记录，包含审核、子任务、预测、标题、压缩和问候；ASR、TTS、Live 暂不纳入。实值、估算、未知和真实零分开处理，缓存与推理属于总量子集，不额外叠加。旧任务汇总无法拆回每日请求时不回填。

账本在当前设置目录的 usage/usage.jsonl，只保存请求元数据与计数；写入失败显示统计警告，不中断模型回复，恢复后补存。它不是服务商账单，也不显示套餐额度。

文件 → 导出当前会话保留导出功能；加载更早历史在确有历史时出现在聊天滚动区顶部。帮助 → 显示键盘快捷键可搜索真实命令；文档、新功能、反馈打开 GitHub 对应页面，配置引导仍使用当前主窗口作为宿主。

空间足够时点击右上工作摘要可固定显示，按钮持续高亮；空间不足时临时展开并在失去焦点后关闭。侧栏收起不会将旧任务统计行放到聊天顶部。自动朗读开关位于头像与对话标题之间，图标提示统一黑底白字圆角。上下文提示仅显示估算比例、已用量和总容量，容量未知不计算比例。

## 开始工作

在模型配置的模型编辑窗口，分别核对工具调用、图片理解和上下文容量。手动能力设置优先，其次采用当前服务明确返回的元数据，缺失时才沿用标注为未经验证的旧兼容判断。更换服务地址会清除该服务的旧能力数据。

工作设置区分项目和无项目默认设置，保存用于下一次请求。已知模型容量优先；未知容量使用兜底值。实际输入预算还会扣除输出、安全、工具和协议开销。压缩摘要失败会停止该请求并保留原历史，可修正后重试。

伙伴、模型配置、工作设置和通用使用统一的标题与标签栏。通用设置分为“外观与交互／快捷键／聊天记录”；快捷键页可编辑 4 项全局快捷键及 29 项窗口命令、导航和菜单快捷键。每行独立保存、留空停用或恢复默认，冲突与系统保留组合会提示；窗口快捷键仅在应用内响应。文本编辑、发送、换行、Tab 和 Esc 等随控件生效的操作另列参考说明。切换标签或刷新设置不会覆盖未保存的快捷键草稿。

已归档内容不再出现在侧边栏，统一在“工作设置 → 已归档对话”管理，覆盖各伙伴的项目、无项目和快速对话。恢复后返回原列表；随项目归档的对话可恢复所属项目。永久删除仍需确认，移除项目记录不会删除工作目录中的源文件。归档页的操作立即生效，不使用工作设置的保存按钮。

对话背景立绘以素材的实际可见轮廓固定在对话背景区域右下角，不跟随消息滚动；审批卡片和待发队列出现时保持原锚点，输入框保持前景遮挡，展开工具或调整窗口时跟随可用对话区域重新定位。

## 工作中也能互动

思考、执行工具和等待回复时，仍可拖动、点击桌宠或打开动作轮盘。互动结束后恢复当前任务动作，流式回复不会抢走拖动捕获。暂停、锁定位置和鼠标穿透仍按各自设置生效。开始新工作会唤醒已有小憩；工作中主动选择的小憩保留。

| 运行情况 | 自动动作 |
| --- | --- |
| 思考、执行工具 | 思考 |
| 整理或输出结果、任务完成 | 检查成果 |
| 等待本次审批、消息排队、执行结果待核对 | 等待 |
| 模型或工具报错 | 短暂委屈，随后随真实状态恢复 |
| 取消或结束反馈 | 待机 |

## 输入区 Markdown

富文本模式下，输入 `**测试**` 后，在格式末尾输入空格或换行，后续文字使用普通格式。默认使用 Shift + Enter 换行；若发送快捷键改为 Ctrl + Enter，则可直接按 Enter 换行。代码块、列表和引用后的草稿换行会保留。

纯文本模式继续显示 Markdown 原始语法，切换模式会保留草稿。

## 聊天、工作与权限

通过顶部「聊天｜工作」切换，各自保留会话和草稿；聊天只显示当前伙伴的个人记录，工作显示项目与共享工作记录。Tab 接受预测建议，Enter 仍可接受；这两个键不会切换入口。完整对话输入框下方会显示当前伙伴名字和核对 AI 回答的提醒；快速对话不显示这条提醒。

完整对话的聊天记录区右下显示当前伙伴立绘，透明度为 20%，向靠近文字的一侧逐渐淡出。立绘位于文字下层，不跟随消息滚动，不进入输入区；历史区较窄时自动减弱，很窄时隐藏。

右键点击消息中的链接，可选择“在侧边标签页打开”“在默认浏览器打开”或“复制链接”。网页标签复用当前窗口，保留对话与草稿；窄窗口自动使用现有标签布局。邮箱链接交由系统打开，不进入网页标签。

思考与工具状态旁显示 20px 伙伴头像。回复完成后，过程会折叠到可再次展开的记录入口，保留头像、耗时及工具记录。回复会保存生成时的伙伴身份；切换伙伴或重新打开历史，不会把过去的头像替换为当前伙伴。

工作输入框的权限入口打开三档菜单：请求批准（外部文件和联网请求交给你确认）、帮我批准（独立审核明确授权的有限操作，不确定或失败转人工）、完全访问权限（以当前账户权限访问，不会自动获得管理员权限）。远程 MCP 和 GitHub 写入始终独立确认，计划模式和只读子任务的禁止规则优先。

权限入口仅显示“请求批准”“帮我批准”“完全访问权限”。新建配置默认“帮我批准”，开启工作区沙箱，终端仍默认关闭；旧配置按原权限运行，不显示内部兼容标记。三个入口使用一致的图标、字号与间距。选择完全访问时显示应用内确认提示，列出文件、终端和联网／应用范围；取消不改变权限，确认后才生效，没有“了解更多”链接。

需要人工确认的操作会显示在对应对话输入框上方。卡片展示命令、工作目录及执行范围，原始参数与来源编号可在“详细信息”展开；选择“拒绝”或“仅本次允许”。切换会话不会迁移或自动批准请求，切回后仍可处理。停止任务会撤下待确认卡片。

`/permissions` 打开菜单；`/permissions ask|auto|full` 切换当前会话；`/sandbox` 查看状态，`/sandbox on|off` 切换隔离。扩大权限会确认，任务运行或有排队消息时需先停止并处理队列。设置页保存全局或项目默认，当前会话覆盖单独保存；旧配置继续沿用原来的文件范围及按条确认方式。

## Windows 工作区沙箱

终端默认关闭，需在工作设置单独启用。新模式可启用原生 AppContainer：每条命令使用独立身份，项目可写，可选工具目录只读，终端及其子进程默认无法联网，临时用户目录独立。沙箱中 PowerShell 的 `workspace:` 指向真实工作目录；原生程序需要路径时使用 `$PWD.ProviderPath` 或绝对路径。模型连接由宿主继续使用配置的服务。

文件、网页及远程工具由宿主按审批执行，它们不是运行在该终端容器中。在“请求批准”和“帮我批准”模式下，Agent 的任意终端命令均逐条交给人工确认，开启沙箱也不跳过；拒绝或在等待确认时取消，不会启动命令。完全访问关闭沙箱。自动审核会额外请求文字模型，与执行任务分开，没有执行工具。

授权目录必须是具体的本地目录，不接受根盘、短名、尾点别名、重解析点或硬链接；单个目录树最多 100000 项。用户目录下的 Python 等工具需显式添加只读安装目录；依赖另外的数据目录也需明确配置。无法验证或启动就停止，不会改为无隔离执行。Windows 系统为应用容器公开的运行时资源仍可读取，不能将它解释为虚拟机或完整磁盘镜像。

执行记录与备份目录由宿主维护，停止继承终端身份授权，并清理原有包授权；这两类目录及后代不能被重新选择为项目或工具目录。普通项目目录只添加临时专属身份权限，并在完成、取消或失败时撤回。超时和停止会结束本次拥有的进程树。

任务面板记录真实退出码、超时／取消和有界输出；较长输出可由任务按输出编号继续读取。停止和超时会结束本次拥有的进程树，已经完成的文件或远程操作需按事实核对。

## 项目说明与技能

Windows 左侧“插件 → 技能 → 添加技能”提供“在发现里浏览”“从 ZIP 安装”“导入本机已有”。本机目录须包含 SKILL.md；导入复制到 data/skills 并登记，保留原目录。

在发现页填写公开 GitHub 仓库地址或 owner/repo，分支留空使用默认分支，点击“添加并刷新”。也可添加同一仓库的不同分支。勾选来源后按名称、描述或仓库搜索，选择“预览”查看实际 SKILL.md 与固定提交，再点击“安装技能”。支持根目录、skills 目录及分类嵌套的技能。安装同时保存该技能目录中的资源及来源，不覆盖同名技能。移除仓库来源保留已安装技能。分支修改保存后需重新刷新。

页面打开时只读上次成功缓存，不自动联网。每个来源显示分支、数量、缓存时间及格式不支持的条目数；刷新失败或取消保留上次成功结果。ZIP 同样先扫描、选择与预览，再安装；会拒绝超限、路径穿越、链接和本机文件名冲突。公开仓库下载使用直连；首版不支持私有仓库、自动更新或跨工具同步。来源和发现缓存位于 data/skill-discovery，技能库登记格式兼容旧版。

技能安装默认启用，启停从下一次工作请求生效；移除立即阻止后续 load_skill 读取，已返回给任务的正文不会撤回。导入失败保留原注册表并隔离未登记副本，允许修正后重试。应用连接和插件包运行时列入 README TODO。

快速对话及普通新对话在首次消息成功加入发送队列时才登记到会话列表。仅打开窗口或输入草稿不会生成空记录，提交失败保留草稿。未发送文字按会话保留在当前运行中的会话状态内，切换 A/B、新建草稿或快速/完整视图可恢复；“新建对话”会返回同项目、模式、伙伴和分区下尚未发送的草稿。发送后清空对应输入，再点新建才开始下一份草稿。该缓存不承诺退出应用后的恢复。

显式开启“信任项目说明与技能”后，任务可读取适用目录的 `AGENTS.md`；可额外指定说明文件和技能目录。说明带有来源与校验值，不能扩展工具权限。

用户显式导入且启用的技能不依赖项目说明信任开关。`/` 菜单只列出真实发现的技能，选择后由任务按需调用 `load_skill`。加载只读取文本及获准目录内资源，不会自动安装扩展或运行脚本。只读 worker 继承相同的项目说明及父任务权限限制。

## 插件与 MCP

在左侧“插件 → MCP”添加并保存服务器，然后主动点击连接。保存或重开应用不会启动连接。HTTP 使用独立加密凭证；URL 中不接受用户名和密码，stdio 参数中不要填写密钥。

当前支持标注的 stdio 与 HTTP JSON 子集，不支持 HTTP SSE。stdio 只在点击连接后启动用户配置的已有程序。连接成功后，新任务获得真实工具目录；审批卡片显示服务器、目标、原始操作及参数。断开会撤下工具，并结束本次拥有的 stdio 进程。计划模式不开放这些工具。

## 独立只读子任务

模型可使用真实 `explore` worker 并行探索：最多四个并行，其余按顺序排队，深度为一级。每个 worker 有自己的历史、预算和真实结果；它们继承父任务拒绝规则，不能写文件、运行终端或继续委派。停止父任务会停止运行及排队中的 worker。

任务面板分别显示当前上下文与累计用量估算，并汇总父、子任务。探索和压缩摘要均可能产生额外模型请求；实际计费以服务端为准。

## 中断、核对与项目事实

副作用先写本地执行记录。若上次操作可能已经发生而结果不能确认，会进入“待核对”，停止后续调用。先检查实际文件或外部状态，再点击“已核对执行记录”。旧调用不会盲目重放，旧审批不能跨重启复用。

文件变更、命令退出码和 worker 结果以实际执行记录为准。保存失败会显示警告并阻止更新退出，包含后台会话。

网页读取失败会作为工具错误交给 Agent 处理。已经开始的 Agent 任务若最终失败，失败记录保留在原对话，后续待发消息暂停；点击“继续队列”不会重新提交已执行过的任务。需要恢复任务时，先核对已有结果，再使用“继续任务”。

任务面板中的“项目事实”打开当前窗口的管理标签页，可手动新增、选中后编辑和删除。适合记录构建方式、目录约定等已经确认的信息，记录来源任务／文件及时间，仅供同项目后续任务引用。空项目显示填写提示，保存后才生效，删除后不再注入；没有自动长期记忆或自动技能创建。管理页与审批、链接菜单均支持浅色和深色主题。

## 文件变更总结

运行中的工作任务在输入框上方浮动显示去重后的文件数与增删行数；点击可在工具标签查看本任务变更。新建文件重复编辑仍以任务开始前的空文件状态为基准，已恢复或回到原内容的文件不计入净变更；未知行数不伪装为零。

任务完成后，浮条收起，每条回复分别保留自己的文件总结，开始下一任务或重开历史不会替换上一条。展开可查看更多文件，文件名和“查看差异”显示该任务原备份与当前文件。仅当前匹配任务在空闲时提供原文件的受控撤销；历史总结只读，新建文件没有原文件备份时不提供伪撤销。嵌套目录和任务中批准的其他路径仍按各自真实备份校验。手动终端的任意外部修改不自动宣称为文件工具记录。

## 最终交付文件

最终回复里的本地文件链接显示为文件卡片，位置为正文、已编辑文件总结、交付文件、回复操作。文件类型使用对应图标，HTML 显示网页标识。点击卡片打开内置预览；右键包含打开文件、打开方式、在资源管理器中打开、复制路径、复制文件内容、另存为。二进制文件不提供复制文字内容；另存为复制真实文件，保留 ZIP 等文件字节，不受输入附件 4 MB 限制。

HTML 默认显示网页，Markdown 显示排版，C# 等文本文件显示带行号的只读源码。可在「预览｜源码」间切换、重新加载文件，或从预览顶部用系统应用打开。文件预览作为工具标签留在主窗口，可与主聊天分屏，或使用下方说明的完整标签视图。HTML 默认只加载当前文件夹中的资源；需要远程图片、脚本或网络数据时，手动打开「外部资源」。网页组件不可用时会显示源码，其他不支持预览的文件可通过右键打开或另存为。

卡片只展示明确提供的本地链接或回复附件，不扫描项目或自动把所有修改列为交付物。工作助手会被要求用 `[文件名](<完整绝对路径>)` 给出最终文件；历史重开仍按原路径显示，移动或删除后显示不可用，不伪造文件。已知当前任务也可解析其相对路径，旧任务不猜测根目录。网页 URL 继续作为普通链接，不会自动下载到本地。


## 分屏、完整标签与工具

完整窗口的“新建标签页”（Ctrl + Shift + B）或标签栏末尾 **+** 打开工具页，支持文件、终端、浏览器、侧边聊天及变更总结。浅色标签栏中，未选中标签以灰色显示，当前标签使用白底、细边框；新建 **+** 紧接最后一个标签，标签较多时可横向滚动。

| 视图 | 使用方式 |

| 分屏视图 | 主聊天在左，工具标签在右；拖动中间分隔线调整宽度，保留可读的最小栏宽 |

在窗口足够宽时，点击视图切换按钮或按 **Ctrl + Shift + F**，可在两种视图间切换。把分隔线持续向左拖，也可进入完整标签视图。窗口变窄时自动使用完整标签视图，拉宽后恢复此前布局；整个过程都在同一主窗口内完成。

切换视图会保留原来的主会话、输入草稿和阅读位置，也保留最近选中的工具标签。点击侧栏中的当前聊天、另一段聊天或新建对话，会选中对应的主聊天标签。使用“隐藏／显示标签页”按钮只改变显示，文件、浏览器、终端与临时聊天保持原状态。关闭工具标签释放对应工具，关闭整个对话窗口释放所有工具；切换主对话不结束已有终端，已有工具继续使用其打开时的项目背景。

完整窗口左下角 **+ → 打开终端** 或 **Ctrl + 反引号** 可启动真实 ConPTY PowerShell 会话，保留目录和变量，支持交互输入、Ctrl + C 和尺寸调整；关闭终端标签结束自己的进程树。手动终端与 Agent 自动工具调用的终端开关及审批流程独立。启动时固定项目、沙箱和只读工具目录，并标明“工作区沙箱”或“当前账户权限”；沙箱失败不会回退，后续修改默认权限不影响已有终端。

浏览器只接受 HTTP/HTTPS 地址，搜索词交给 Bing，空页不自动联网；与 HTML 文件预览的资源开关独立。内置浏览器禁用宿主消息桥、外部协议启动和自动下载，权限请求默认拒绝；当前不提供下载。**Ctrl + Alt + S** 打开侧边聊天，它冻结当前项目与模型设置，不读取主对话、其他临时聊天或项目文件，无执行工具、不写入历史，关闭会取消自己的请求。

主对话滚动条位于整个主区域最右沿，正文保持独立阅读宽度；翻阅较早消息后可用输入区上方的“一键到底”返回最新内容。摘要显隐按钮固定在主对话右上角，新建和隐藏标签控制留在工具区右上方。摘要使用独立圆角悬浮卡片，旁边没有贯穿窗口高度的分隔线。空间不足或进入完整标签视图时自动收起固定摘要，空间恢复后重新显示；手动隐藏偏好继续保持。点击摘要按钮可临时弹出，焦点离开或点击其他区域后收起。文件名打开实际文件预览，差异、命令输出、子任务详情可在工具标签中查看。
