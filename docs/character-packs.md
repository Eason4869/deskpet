# 完整角色资源包与更新

应用内置 E 包默认高清动作与头像，可离线启动；完整官方包另含全部已发布节日服装，可对包括 E 包在内的五位伙伴执行全量下载／更新。其他四位官方伙伴保留在列表中，选择后自动下载兼容的完整角色包，并在后台校验、安装后切换。

下载沿用应用更新的 GitHub 加速地址和代理设置。桌宠右键切换会用不抢焦点的提示告知下载进度；设置页和主界面使用进度窗口。首次引导期间即可选择伙伴并在后台准备缺失素材，也可明确点击全量下载／更新；准备期间可以继续引导，关闭引导不会取消下载。

设置中 **导入 / 更新角色包** 后的 **全量下载／更新** 可一次获取五位官方伙伴的完整包；已安装且校验一致的版本会跳过。取消或个别下载失败不会删除已安装素材，也不会改变当前伙伴的人格、音色或聊天记录。应用更新后会在后台检查当前选择的官方伙伴（含 E 包），有可用旧素材时继续使用；缺少素材时临时显示 E 包并记住待恢复的伙伴。

自定义角色仍可直接导入 ZIP：设置 → 选择伙伴 → **导入 / 更新角色包**。同一自定义包 ID 更新素材，保留个人数据。自定义包即使使用官方角色的 ID，也不会覆盖官方入口或获得官方节日解锁身份。

标准 v2 仍保持 17 个动作、4×4 视线及 480×520 预览；旧 PNG／v1／无 ID 的 v2 继续兼容。完整示例是 [`assets/bundled-skins/gugugaga/pet.json`](../assets/bundled-skins/gugugaga/pet.json)。

官方完整包名为 `DeskPet-Companion-角色ID-版本.zip`，例如 `DeskPet-Companion-gugugaga-0.11.0-dev.3.zip`；包内 `pack_version` 随素材更新，固定 `id` 仍为 `gugugaga`。`DeskPet-Companions-版本.json` 是五位官方伙伴的完整目录。仓库中的旧咕嘎示例仍保留其原始 `pack_version`，完整包由构建工具另行生成，不改写原始素材。

可选字段：

| 字段 | 用途 |
| --- | --- |
| `id` | 固定包身份，小写字母、数字、短横线，最多 48 字符；更新时保持不变 |
| `pack_version` | 包版本说明，最多 32 字符；用户可重新导入旧版进行回退 |
| `avatar` | 包内正方形 PNG 相对路径，64–2048 像素 |
| `extra_animations` | 第一套额外动作：`stumble`、`special2`，可分别提供 |
| `alternate_animations` | 第二套：`lifted`、`landing`、`feeding`、`happy`、`sleeping`、`special`、`special2`、`stumble`、`jumping` |
| `special_action2` | 第二招牌名称，最多 32 字 |
| `voice_presets` | `speech` / `live` 候选 ID 数组，以及 `description` 声音目标、`sample_text` 试听文本 |

扩展动作与标准动作一样声明 `file`、`columns`、`frames`、`fps`、`loop`。非循环跳跃可用 `hold_last_seconds` 声明最后一帧的额外停留，范围为 0–2 秒。第二套必须有对应第一套；两套循环方式一致，跳跃的播放加停留总时长一致。播放按包内 FPS，不把所有包强制为一秒。拖起→落地／踉跄、喂食→开心保持选定版本。

声音推荐只从当前服务、模型支持的现有预置目录中选；已有的手动音色优先，不因更新包覆盖。普通聊天人格、声音目标和试听台词随包更新，工作模式提示词不变。咕嘎的推荐候选为 MiMo `冰糖`、OpenAI `shimmer`（备用 `nova`）、Gemini Live `Leda`（备用 `Zephyr`）；它们是待试听预设，不是原角色声音复刻。依据与服务范围见 [音色文档](voice-presets.md)。

ZIP 根目录放 `pet.json`，只包含图片和说明数据，不包含脚本。导入器限制路径、解压总量、条目数与每项大小，拒绝越界、重复路径和链接；完成全部素材校验后再更新当前版本。

## 避免重复和保留个人数据

- 有固定 ID 的包安装在 `data/companion-packs/<id>/v-<guid>/`；`current.txt` 原子指向有效版本。保留前版，不覆写正在使用的素材。
- 官方下载单独存入 `data/official-companions/<id>/`，完整校验后才切换版本指针。旧版原始小贝、咕嘎缓存只有在素材哈希和动作、人格信息均匹配时才作为可信旧素材继续使用；旧默认包不会被标记为完整节日包。
- 官方入口优先使用校验通过的已安装官方版本；同 ID 的自定义导入保留独立入口和个人身份。应用升级及同来源更新不会复制伙伴或覆盖人格、音色、聊天记录。
- 旧引擎导入会产生 `skin-<guid>`。对原版无 ID 的 v2，只有名称、默认人格、标准动作、视线及可用预览完全核对后，才与已知包合并；保留原个人 ID，并把对应关系记录在 `identity.txt`，不用移动聊天记录。修改过的自定义设计保持独立。
- 重复导入同一旧原版会返回已经保留的个人身份，不产生新的可见重复项。
- 无 ID 的普通自制外观仍独立保存。仅凭名字相同不会覆盖；建议发布者提供固定 `id`。

## 删除和恢复

下拉列表提供“从列表移除”操作。默认官方 E 包用于离线启动，保留在列表中，不能删除；其他伙伴可移除。移除当前伙伴会先切到另一位可用伙伴。该操作只从列表移除，素材、人格、音色与聊天保留；可以点击“恢复已删除伙伴”，自定义固定 ID 包也可通过重新导入恢复。

移除状态保存在 `data/companion-packs/removed.txt`。这与永久清空聊天是两个不同操作。

旧 PNG／v1／标准 v2 自定义导入仍保留。官方完整包需要支持官方目录、独立安装位置与节日素材的新版本应用；旧版不会把资源专用发行版当作应用更新。


## 0.11.1：独立素材版本

官方目录 JSON 使用发行版本号，角色 ZIP 使用逐角色素材版本（`DeskPet-Companion-<id>-<pack_version>.zip`）。`pack_version`、`min_app_version` 与应用发行号分别记录在 `assets/official/companion-versions.json`；仅应用升级不改变素材版本或 ZIP 字节。最低应用版本按完整安装与动作能力保守设置，不自动降到早期 v2 格式版本。

已验证的相同 ZIP 复用原安装根，不改写安装收据；检查或复用不显示下载提示。远端版本/衣装声明与相同字节冲突时保留原素材并报告异常，不宣称更新完成。历史版本因改写包内字段而产生不同摘要时，可能需要一次完整迁移下载。已发布附件不改写。


## 0.11.1：受保护的历史副本

新安装使用独立的 `v2-<素材版本>-<摘要前缀>-<随机标识>` 缓存目录和第 2 版安装收据；ZIP 格式与完整 SHA256 校验不变。旧客户端不能选择这些受管目录。旧 `v-*` 安装仍可读取，但不会自动采用为可删除对象，也不改写原收据。旧应用再次运行时可能需要恢复自己的兼容缓存。

设置中的清理缓存新增“角色包历史副本”。只回收有明确归属、退役超过七天、无使用租约且非当前/前版本的受管目录。当前、一个已验证的恢复前版本、使用中或状态不明的素材及旧格式副本均保留。当前进程保守地持有已使用版本的租约直到退出，因此部分副本要在重启后才可清理；不会声称磁盘始终恰好只有两份。

安装切换先保存事务，再原子提交 current；成功后完成前版本和退役记录。中断状态先保护后恢复，不能因清理失败回滚已经生效的 current。仅从列表移除伙伴不会释放其聊天、配置、关系或可恢复素材；自定义包的历史版本不在本轮回收范围。


### 安装后的自动维护

仅在官方包真正安装成功后排队执行历史清理；检查版本、复用已安装内容不会启动下载或额外清理。自动维护只处理符合手动策略的角色包历史，不删除更新包或下载缓存。当前、前版本、在用和未知素材仍保留，退出会取消维护并有界等待释放句柄。

每次维护的数字摘要保存在 `data/cache-maintenance/last-companion-history.json`，只记录时间、体积和成功/跳过/失败数量，不写入密钥或错误正文。维护或摘要写入失败不会把成功更新显示为失败。若删除中途遇到文件占用或存储错误，无法完整复验的剩余副本会继续受到保护，不进行推测性删除；后续扫描会如实报告保护/跳过数量。

离线查询仍逐文件验证当前安装。优化只消除同一次受管查询内的重复验证，不跨查询永久信任文件大小、修改时间或历史成功结果。

构建导出的源码时没有 Git 历史可追溯，仍要求每个角色的完整内容匹配已记录的素材摘要。CI 另行执行严格的素材历史门禁，需要完整 checkout；浅克隆会被拒绝，源码导出也不会借用父目录仓库的历史。
