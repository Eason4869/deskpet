# 0.11.2-dev.2 提示与节日纪念卡修复

日期：2026-10-27。基于 v0.11.2-dev.1 源码提交 9e8fe30。显示版本 0.11.2-dev.2，数字程序集版本继续使用 0.11.2.0。目标分支为 dev；不改动 main 0.11.1、既有 v0.11.2-dev.1 标签或 GitHub Releases。

## 行为

- 好感度提示、阶段升级和互动问候共用约 900 ms 的完整生命周期：100 ms 淡入、650 ms 展示、150 ms 淡出。合并收益或迟到文案只更新内容，不重新计时。
- “你好呀”等阶段互动问候按 10% 概率选择；概率只影响文案，不影响原有互动记账、冷却和收益。未选中问候时，真实加分仍会弹出；既没有加分也未选中问候时不创建提示。
- 节日纪念册只渲染当前伙伴已解锁、成功保存的卡片。移除资源可用但未获得的预览卡和预览选择器；实际解锁、历史年份、分页、保存图片、错误恢复和伙伴隔离保留。
- 13 个语言包内容未改写；两个不再出现在界面的锁定预览资源键保留为历史资源并登记停用原因。
