# 0.11.0-dev.1 功能闭环补充设计

日期：2026-10-24。基线仍为 `v0.10.5-dev.3`。本文承接 `implementation-plan.md`，记录开发过程中实际发现的缺口。

用户追加要求：完整分析遗漏，补充计划并实施，确保新增功能都有界面和入口，完成测试和安装包验证。用户已明确本轮不做 MSI；本轮 Windows 交付继续采用现有 Inno Setup EXE 和便携 ZIP。

## 目标与边界

补齐已经承诺的伙伴关系和维护功能的入口、展示、状态解释和恢复闭环。后台接口存在或单项测试通过，不等于用户已经能使用完整功能。

延续共享 C# 逻辑、WPF 和 Avalonia 两套界面、现有导航与主题；不增加新 UI 框架、安装技术、网络依赖或资源生成服务。不扩展装扮收藏、角色故事、心情及记忆管理，不增加全局数据清除或自动修复坏数据的按钮。

## 采用的方法

1. 仅完成原有待办：成本最低，但会留下已发现的文案未接通、无预览及查找困难。
2. **补齐已有功能闭环：采用。** 在现有页面、欢迎/互动通道和维护流程内完善入口与恢复，保留既有产品结构。
3. 顺带新增 MSI、故事、收藏或新的通知中心：会引入独立状态和迁移问题，超出本轮目标，排除。

这是根据用户“补充后继续完善”的授权作出的实施选择，不把实现者选择伪称为用户逐项指定的设计。

## S1：阶段内容真正进入角色表现

共享内容读取必须基于成功保存的关系快照，在工作线程完成。失败时沿用现有行为，不能伪造“初识”状态。捕获伙伴身份、内容包、语言和交互序号；等待后再次检查当前伙伴、免打扰及窗口生命周期，丢弃过时响应。

- 只在用户发起且角色实际执行的互动路径调用阶段互动回应。自动庆祝、节日动作、随机动作和旧事件重放不能触发该回应或额外加分。
- 使用已有非抢焦点文字气泡/展示组件；不打断聊天、录音、Live 或受保护动作，不新增强制语音及模型请求。收益提示与互动台词分别负责各自语义，避免堆叠窗口。
- 正常欢迎沿用既有允许条件、调度与节日优先级；配置预览也保持现有语义。非 AI 欢迎可在本次应用会话中首次符合条件的伙伴/阶段欢迎槽使用已解锁文案，成功显示后标记；之后继续现有时段/随机欢迎，避免每次重复同一句。
- AI 欢迎保留既有生成及人格/偏好优先级。只有启用关系 AI 上下文时才传入简短阶段说明；本地阶段文案可用于既有非 AI/失败回退，不绕过 AI 上下文关闭设置。
- 欢迎与回应来自内容包，缺失时使用通用阶段文案；不捏造用户昵称、记忆或经历，不新建离线补发队列。

## S2：主页展示、纪念卡和恢复

- 每个已解锁纪念卡提供明确“预览”入口，在主页内展开实际图像，窄窗口等比缩放。头像、名字、阶段、日期来自同一捕获的数据；保存复用同一图像。未导出不创建文件，取消无成功提示。
- 显示“成长已暂停”“今日已达上限”“已达最高阶段”等适用状态。关系设置明确作用于所有伙伴，不增加每日任务清单。
- 将读取/保存异常、待保存状态与重试放到关系卡附近。临时失败提供有效重试；无法在进程内恢复的情况明确说明重启要求并复用安全重启能力，不能自动删除/覆盖未知或损坏数据。提供用户主动打开关系数据目录的恢复入口，路径不作为日常信息铺满页面。
- 自动刷新保留当前伙伴的简介/规则/设置展开状态、纪念卡预览状态和合理滚动位置。不能因为后台积分到账夺取焦点；异步完成不能把焦点从另一窗口拉回。切换伙伴后不能混用旧预览。
- 延续当前串行设置保存、保存失败重试、跨页通知及免打扰逻辑。

## S3：发现入口与数据管理结果闭环

- WPF 设置搜索使用当前语言可见的功能名/定位词，能定位“清理缓存”“数据管理”“清空聊天记录”“恢复默认设置”“关系设置/伙伴主页”的相应位置。利用现有导航与关联入口，不另建主页或直接触发删除。
- 没有全局设置搜索的原生界面，不为此重写整套设置；保证 General 数据管理、About 缓存及伙伴菜单各自入口清晰，并提供必要关联跳转。
- M5b3 提供“查看保留附件”，使用服务的 `AttachmentDirectory`；不存在任何已归档文件时禁用或给出明确空状态。
- `RemovedFiles` 是文件数量，不显示成“清理了 N 个对话”。`Partial` 可以是零删除；保存/读取失败时如实解释。持久队列不可读/未完成时展示阻塞原因和有用处理方式，不只给无限重试。
- 确认文案写明保留设置/密钥/角色/图片/关系/草稿/明确保存的项目资料。源码、执行幂等与进程所有权记录保持保护。

## 验收与交付

每项必须有“用户从哪里进入—看到什么—怎样操作—成功/失败/取消后怎样恢复”的用例；不能只靠源代码字符串检查或后台单元测试证明有界面。

- 两端真实控件路径覆盖阶段文案、预览/保存、状态与错误入口；验证键盘访问、窄宽、明暗主题和长语言文本。
- 关系保存失败、不支持的新数据版本、免打扰、伙伴切换、后台刷新和关闭后的迟到回调都必须有对应回归。
- M6 解决已登记的缓存 JSON null、懒创建日志索引、语言键名/字面量/来源审计、旧引导烟测及更新助手测试夹具问题；保留原失败与修复证据。
- 在已提交的实际产品代码上更新 `0.11.0-dev.1`、构建 EXE/ZIP，记录构建提交与哈希。安装、升级和卸载在独立测试注册项、互斥量、单实例/唤醒通道或隔离用户中进行，不碰正在使用的安装。
- Windows 实际桌面、Avalonia 无头验证、macOS 实机、安装包、远端 CI、tag/Release 分别报告；未执行的项目明确写未执行。
- MSI 明确不进入本轮；未来存在明确 MSI 部署需求时，再独立设计版本映射、安装识别、EXE/MSI 迁移、升级回滚和卸载矩阵。
