# 新增功能入口与用户流程验收表

本表是交付门禁，不是完成声明。状态以独立审阅和 `acceptance.md` 的实际证据为准；2026-10-24 补充阶段尚在实施。

| 功能 | 用户入口 / 操作 | 成功结果 | 失败、取消与状态要求 | 验证位置 |
| --- | --- | --- | --- | --- |
| 当前伙伴主页 | 主窗口左下头像菜单 → 原色伙伴信息行 | 同一主窗口显示当前伙伴，返回保留草稿 | 键盘可达，切换伙伴不混用头像/分数 | 两端 CompanionHome UI |
| 关系与成长规则 | 主页关系卡 → 成长规则 | 显示真实分数、阶段、今日增长及两类天数 | 暂停/每日上限/最高阶段有说明；无每日强制任务 | 共享规则/投影及两端 UI |
| 关系开关 | 主页 → 关系设置；设置中的关联定位 | 保存后改变行为 | 说明作用于所有伙伴；失败不伪装成功；连续操作不覆盖新选择 | Presentation / Feedback / Home UI |
| 阶段欢迎 | 已启用主动问候的既有正常欢迎流程 | 合适条件下显示对应内容或 AI/通用回退 | 节日、人格、免打扰、AI 上下文关闭与取消优先级正确 | S1 实际欢迎路径 |
| 阶段互动回应 | 用户实际执行摸头、投喂等已支持互动 | 显示对应阶段的角色/通用台词 | 不抢焦点，不另加分；关闭反馈/免打扰静默；旧伙伴迟到结果丢弃 | S1 实际互动路径 |
| 轻量收益与升级卡 | 日常有效事件保存成功后 | 合并 +N，阶段提示一次，主页可回看；圆角气泡、略小字号、姓名位于头像右侧 | 保存失败不弹成功，免打扰不补播，自动动作不加分；沿用现有浅深色风格 | Feedback / F1 实际窗口 |
| 纪念卡预览 | 主页已解锁卡片 → 预览 | 主页内显示真实图像，窄屏等比适配 | 不落盘、不串图；后台刷新不折叠或抢焦点 | S2 Home UI |
| 保存纪念卡 | 预览/卡片 → 保存 → 原生保存对话框 | 生成包含头像/名字/阶段/日期的 PNG | 取消无副作用；写失败保留旧文件且不报成功 | 两端 PNG / 文件保存 / 实际对话框 |
| 关系异常恢复 | 关系卡附近警告 → 有效重试 / 恢复说明 / 打开关系数据目录 | 正常可恢复问题回到已保存状态 | 坏文件/未来数据保留；必须重启时说明并使用安全入口 | S2 读取/保存/恢复 UI |
| 查找新增功能 | WPF 设置搜索 → 对应类别和子页；原生明确分组入口 | 定位缓存、数据管理、聊天清理、重置和关系入口 | 搜索只导航，不自动清空/重置/卸载；窄屏仍有菜单路径 | S3 SettingsNavigation / 原生入口 |
| 缓存清理 | 关于 → 灰色“清理缓存” → 扫描 → 清理 | 实际分类空间、释放量和结果 | 0 空间禁用；保护项、失败项说明；取消/Esc/X 桌宠继续 | Cache core / 两端 Cache UI |
| 清空聊天记录 | 通用 → 数据管理 → 清空聊天记录 → 独立确认 | 清除全部目标历史与会话上下文，已保留附件可取回 | Busy/Partial 真实；保留草稿、关系、密钥、项目资料/源文件；不可读文件不误删 | HistoryMaintenance / 两端 Data UI |
| 查看保留附件 | 通用 → 数据管理 → 查看保留附件 | 打开实际归档目录 | 没有附件时明确空状态；打开失败有提示；不创建虚假文件 | 两端 Data UI / 原文件读回 |
| 恢复默认偏好 | 通用 → 数据管理 → 恢复默认设置 → 独立确认 | 只恢复已声明偏好并应用运行时状态 | 保存失败回滚；保留模型密钥、人设、项目、关系、历史及更新通道 | Reset 事务 / 两端 Data UI |
| 卸载确认 | 关于 → 红色“卸载” → 应用内确认 | 确认后可信助手安全交接安装器 | 取消/Esc/X 不退出；忙碌/准备失败保持应用；便携版说明限制 | M5c 确认 UI / 真实隔离安装 |
| 安装、升级、卸载 | EXE 安装器；便携 ZIP 解压 | 身份一致、升级保留数据、卸载保留用户资料 | 隔离注册与 IPC；不得操纵当前用户安装；不增加 MSI | M6 安装包矩阵 |

每个界面功能至少有一个实际控件/导航用例，不能只引用后台 API 测试。自动化、Windows 桌面交互、Avalonia 无头、macOS 实机和安装包结果分别记录。尚未执行的项目必须明确注明。

阶段补充设计与执行顺序：[设计说明](completeness-design.md)、[实施计划](completeness-plan.md)。
