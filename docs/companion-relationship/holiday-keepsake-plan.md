# H1 万圣节纪念卡实施计划

需求依据：holiday-keepsake-design.md。先完成F3，再按H1a、H1b顺序实施和独立审阅；之后继续M5c2、S1、S3、M6。禁止MSI、推送、发布、操作真实用户数据或当前桌面。共享逻辑兼容C#5；两端使用同一规则。测试时钟只注入自有fixture。

## H1a：可信领取与永久保存

1. 固定只读事件、记录、结果、相册、预览和肖像DTO；复用HolidayCalendar、RelationshipTime和稳定伙伴身份。最早2026，Halloween InstanceKey来自现有日历。状态与每卡资源错误分离。
2. 先写规则测试：10月30/31日、11月1日、2025拒绝/2027新年度、跨伙伴全局水位、重启去重、UTC/offset一致性、失败不虚报、同名不同身份、换装同身份。
3. 新建commemorations独立store，严格schema版本、事务文件锁、受控哈希blob、同目录原子发布。先blob后记录，未知版本/损坏状态保留；单卡丢失blob可读元数据，不阻塞其他卡。限额保留原有数据。
4. WPF/Avalonia提供完整PNG解码验证适配器，4 MiB/480×520/透明像素，所有图像资源及时释放。校验原始字节，不改写官方资源。
5. 实现有序异步runtime：入队前取得维护活动租约、单次事件冻结身份时间和可信资源来源、跨进程reload后去重、成功提交后通知、关闭排空。失败重试是新资格检查，preview/list只读且不落盘。
6. 验证两进程竞争、失败与未知版本、假合法PNG损坏压缩流、维护排空、资源移除后仍可读、三种数据清理操作保留整个commemorations目录。交付确切API和线程/字节所有权说明后独立审阅。

## H1b：实际见面与节日纪念册

1. 两端新增小型事件适配器：真实已显示伙伴或已显示主页触发；隐藏、锁屏、后台刷新、构造控件不触发。跨午夜仍显示的伙伴通过实际帧或已确认可见探测触发。免打扰和未穿节日衣服仍可静默领取。
2. 主页纪念册提供关系/节日分类、已保存数量、本年度锁定预览、取得日期、错误及当前资格重试。保护异步身份/页面版本，状态来自提交成功结果。锁定预览无已获导出入口。
3. 复用F3静态肖像和800×480导出布局，实际节日服饰、南瓜灯/蝙蝠图案、节日年度与纪念短句；浅深卡体均与页面区分。用保存时冻结的姓名/服饰/日期，预览与导出字节一致。
4. 13语言新增literal camelCase资源，长语言边界、窄宽布局、键盘焦点、切换主题/伙伴、损坏肖像和空状态均验证。保持原关系卡行为。
5. 真实截图覆盖五位官方伙伴万圣节、两端浅深、锁定和已获；保存输出使用实际渲染字节。记录模拟日期，不宣称当前日期已经解锁或macOS硬件通过。
6. 独立审阅后纳入M6最终功能入口、测试、EXE/ZIP安装/升级/卸载数据保留矩阵。设计稿与实际运行截图分别标明。
