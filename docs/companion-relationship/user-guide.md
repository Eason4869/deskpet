本文对应 `0.11.0-dev.1` 源码预览。[本地验收摘要](acceptance.md)记录 Windows 候选验证与平台边界；macOS 实机尚未验收。源码标签不等于发布二进制 Release。

## 打开主页与查找功能

在主窗口左下头像菜单中点击当前伙伴信息行，打开同一窗口中的伙伴主页。返回原页面时保留原有聊天草稿；主页显示当前伙伴的原色形象、介绍、已保存关系、成长规则和纪念。长介绍及阶段留言可以展开。切换伙伴后，形象、分数和纪念均跟随稳定身份。

左侧卡片上方完整展示当前伙伴最高已获得阶段的原始插画，下方只保留头像、姓名和角色介绍。官方伙伴还没有任何关系记录时使用初见插画作为介绍，不因此生成分数、日期或已获得纪念。自定义伙伴和无法读取的新档案使用自己的安全形象回退；已有同身份快照遇到读取警告时可保留上次成功内容。阶段欢迎语位于右侧关系卡的统计信息后。

Windows 设置搜索可以查找伙伴主页、关系、缓存、聊天记录和恢复默认偏好，并定位实际类别或子页。搜索只负责导航，清空、重置和卸载仍有各自的确认。原生界面保留明确的伙伴主页、通用数据管理及关于/缓存入口，不增加一套虚构的全局搜索。

## 怎样成长

每位伙伴单独保存分数，关系开关作用于所有伙伴。当前默认阶段阈值是 `0 / 80 / 240 / 480 / 760 / 1000`；总分最高 1000，不需要每天完成一份任务清单。

| 有效事件 | 单次收益 | 每日该类上限 |
| --- | ---: | ---: |
| 实际见面或打开该伙伴主页 | +2 | 2 |
| 用户实际触发的受支持互动 | +1 | 6；奖励互动之间至少 20 秒 |
| 成功完成一轮对话 | +2 | 8 |
| 成功完成根工作任务 | +4 | 8 |

每日合计最多 20 点。失败、取消、重复完成、内部子任务、自动动作和后台恢复不会额外结算；工作始终归属创建时绑定的伙伴。升级不会根据旧聊天或历史任务补造关系。分数和提示以成功保存为前提，失败时保留待处理记录并显示警告。

普通好感度提示会向上淡入，短暂停留约一秒后向上淡出；连续收益会合并。互动回应和阶段成长提示保留更长阅读时间。提示会避让伙伴；极端空间不足时不显示气泡，已保存的成长仍可在伙伴主页查看。

“相识天数”是自首次相识起的日历天数，“有效相处”记录实际活动日。日预算根据真实经过的本地午夜推进；单独改时区或回拨时钟不会额外刷新预算。没有因当天未上线而扣分的规则。

关闭“关系成长”会保留已有关系，并停止新增长；重新开启不会追补关闭期间的事件。关闭“关系反馈”会清除当前/待显示提示，之后开启也不补播。关闭 AI 阶段上下文后，不再附加关系阶段说明；自定义人格和明确偏好仍优先。正常欢迎沿用已有问候入口和节日/AI 优先级，阶段互动回应沿用实际支持的用户动作，不另加分。

## 预览和保存纪念卡

主页可回看已保存的阶段纪念。卡片右侧渐变保证文字可读，标题下使用与阶段或节日对应的细节装饰；人物完整保留在画面中。预览与保存使用同一份冻结图片，导出完整的 **800×480 PNG**，包括伙伴名称、阶段、真实达成日期、阶段纪念短句及可用的达成时相识天数。缺失或倒置日期不会编造天数。

点击保存后选择位置；取消不写文件，失败会显示错误并允许重试，不把失败当作成功。已保存 PNG 属于用户资料，不作为缓存清理。系统保存对话框和 macOS 实机交互需要各平台分别验收。

## 节日纪念

节日预览不代表已经拥有。当前获取注册表只启用 **2026 年起的万圣节**；显示在日历中的其他节日并不自动成为可获取的纪念。系统根据实际本地节日日期、受信任的官方伙伴身份和匹配的场景资源判断资格。无需正在穿对应服装；免打扰或关闭关系成长也不会抹去已经拥有的纪念。

在当天实际显示伙伴或打开该伙伴主页，才会尝试保存该年的节日纪念；纯后台加载、读取相册及看锁定预览不会获得。按伙伴、节日和该次年度实例去重，不另外发放好感度或衣装。失败可在仍符合当天条件时重新触发真实见面；跨过日期后不会补领，更不会自动追补往年节日。

拥有后保存原场景 PNG 和当时的名称、日期、衣装/场景版本及哈希。之后换装、更新或缺少原始角色包，不会把这张纪念替换成新图。图片损坏时保留记录及可显示的历史事实，不虚构图片或数量。将来增加节日需要受控日历定义、注册表、身份/衣装映射和已校验场景，不能靠可选角色包任意声明一个节日来获取。

## 数据维护与恢复

**关于 → 清理缓存** 会扫描过期更新包和遗留下载，只清理已确认归属、超过七天且未使用的缓存；活动、待安装、状态不明、链接越界或扫描后发生变化的文件会保护或跳过。显示实际释放字节及失败/跳过数量。图片、附件、关系、纪念、聊天、密钥和项目资料不是清理对象。

**通用 → 数据管理 → 清空聊天记录** 清除所有伙伴/项目聊天、模型会话上下文及已完成任务回放上下文。保留未发送草稿及附件、图片和保留附件、模型配置/密钥、人设/语音、关系/纪念及设置、项目设置/源文件和明确保存的项目资料。它不隐藏保存一份聊天副本。无法安全处理的文件会给出部分失败结果并保留原件。

**查看保留附件** 在重启后仍可取回清空聊天时独立保留的内嵌原件；无附件和打开失败分别说明。**恢复默认偏好** 只恢复界面/行为/问候、免打扰等显示交互选项、聊天显示保存选项、图片并发/动效/图库及快捷键；保留语言、模型服务与密钥、人设、语音、历史、图片、关系/纪念、项目资料、更新通道和引导进度。完整字段表见 [数据管理](data-management.md)。

维护进行前会重新检查忙碌和待保存状态。取消、Esc、关闭确认窗口不会执行操作；执行中的结果必须等到完成。读取损坏文件或较新格式时保留原件；关系区/纪念册可显示警告、重试或打开数据目录。只有明确要求重启的队列问题才按说明处理文件后重启；不要删文件来消除警告。备份或恢复时退出应用并保留整个 `data`，包括 `relationships`、`commemorations` 和保留附件目录。

**关于 → 卸载** 先进行应用内确认。取消、Esc 或关闭不会退出伙伴；忙碌、保存失败或准备失败会保持运行并说明原因。安装版确认后由可信助手等待精确的应用所有者完成退出，再交接已注册卸载器。便携版或注册不匹配时只给出手动移除程序文件并保留 `data` 的说明。最终安装包中的实际卸载行为单独验收，不能由这一说明推定已验证。
