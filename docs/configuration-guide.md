# 配置与使用引导

本页对应 Windows WPF 当前开发版。引导包含分章节的小步骤，具体顺序与已完成进度以应用内引导为准。

整体顺序：选择语言 → 应用并继续 → “开始之前”了解用时 → 蓝色“开始引导”或灰色“我自己探索” → 恭喜页面。选择“我自己探索”会跳过正式配置步骤，直接进入恭喜页面；最后点击“完成引导”才记录完成状态。正式引导中可跳过本步或本章、稍后继续及结束引导。进度按稳定步骤编号保存；完成阅读、保存配置、实际测试分别记录。结尾点击“完成引导”后打开完整对话。

文字测试、朗读、录音、Live 和 MCP 连接均需主动操作；云端服务可能产生费用。审批练习只展示确认窗口，不执行命令，也不计为终端验证。

首次设置先配置 GitHub 下载加速，再选择伙伴，并强烈建议明确点击“下载并更新全量官方角色包”。下载归应用所有，进行后续引导或关闭引导时继续；退出应用会停止。可保留当前可用角色，稍后返回查看进度、取消或重试。

首页先选择界面语言，点击“应用并继续”后立即切换并进入“开始之前”。未打开主窗口时引导在当前工作区居中；有主窗口时固定紧靠其右侧，切换步骤保持稳定。

## 1. 伙伴与入口

### 1. 选择你的语言

选择界面语言后，点击本页的“应用并继续”立即生效并进入下一步。普通语言弹窗在保存后立即生效，取消不改变语言。

### 2. 开始之前

完成完整引导参考用时：约 15–25 分钟。角色包下载和模型服务配置可能需要额外时间；您可以随时保存进度，稍后继续。

这份引导会带您逐步认识桌面伙伴，不必一次完成所有设置。

“跳过本步”：略过当前操作。
“跳过本章”：略过这一整章，继续后面的内容。
“稍后继续”：保存进度，下次从这里接着看。
“结束引导”：退出本次引导，以后可从设置重新打开。

您可以随时使用这些按钮。在引导中，主动选择角色、开始下载或点击测试会发起相应网络请求；播放声音或开启麦克风需您主动操作。

### 3. 更新网络与 AI 网络分开

GitHub 线路只用于应用更新和官方角色包；AI 服务代理需分别配置。选择直连、GitHub 加速或代理，不能确定时先用直连。不会自动安装更新或下载全部角色包。

### 4. 可选：手动测试加速地址

点击“测试连通性”查询镜像状态与耗时；只有你点击才请求网络，不安装更新。自定义镜像地址应先填写并测试，失败会回退 GitHub 直连。

### 5. 保存更新网络设置

点击“保存并继续”验证并保存当前网络地址。未启用的分支不要求填写；代理默认 http://127.0.0.1:7890。

### 6. 选择更新渠道

正式版（main）适合日常稳定使用，仅接收正式更新；预览版（dev）适合提前体验新功能，可能不稳定，也会接收更高正式版。引导高亮“关于”设置中的实际渠道选择框，保留当前选择，按需切换即保存；切换不会降级，也不会立即下载或安装更新。Avalonia 桌面端通过“关于”手动下载，引导提供发布页入口。

### 7. 选择伙伴

应用已内置 E 包完整角色。可在引导中选择伙伴：已安装的角色先显示，缺失或需要更新的角色包会在后台准备，完成后加载最后选择的伙伴；期间可以继续后续引导。人格与声音偏好按伙伴分别保存。

### 8. 强烈建议下载并更新全量官方角色包

全量素材可提供完整动作和角色外观。明确点击后在后台检查、下载并更新；您可以继续后续引导。已有角色在更新时继续显示，退出应用会停止下载。

点击主按钮才开始下载；也可跳过或稍后下载。后续仍可打开进度查看窗口，关闭该窗口不会取消应用后台准备。失败或取消后可以重试，不删除已有可用角色包。

### 9. 记住设置入口

以后可以从桌宠右键菜单打开设置，也可从完整对话窗口的齿轮进入。设置左下角“配置引导”可再次打开本教程。

## 2. 人格

### 10. 修改或恢复人格

人设控制普通聊天的身份和语气，{pet_name} 会替换为伙伴名。可调整称呼、风格或恢复预设；正文不能为空，恢复预设会覆盖草稿，完成后保存。工作模式另用工作提示词。

### 11. 保存人格

点击下方“保存并继续”保存当前人格。只有保存成功才会前进；保存失败时留在本步并显示原因。

## 3. 陪伴方式

### 12. 调整桌宠大小

拖动滑块，观察桌宠大小；这是即时生效的设置。保留当前大小也可以，不会要求你修改每个开关。

### 13. 选择视线与散步

跟随鼠标和自动散步都可按习惯开关；关闭散步仍可手动拖动。鼠标放在伙伴上会暂停散步。

### 14. 拖放反应

拖放踉跄控制松手后的反馈，是否有此动作取决于当前外观。关闭不会阻止拖动。思考和工作中仍可拖动、点击互动或打开动作轮盘，结束后恢复当前任务动作。

### 15. 自动小憩

开启后，伙伴空闲一段时间可以进入小憩；互动后恢复。引导期间暂停自动小憩，避免遮住实操。

### 16. 窗口与启动

置顶让伙伴显示在其他窗口上方；挡住内容时可关闭或拖到边缘。开机启动按需开启，启用后才注册启动项。

## 4. 拖动

### 17. 实操：拖动伙伴

在角色不透明的身体上按住鼠标左键，移动一小段再松开。实际移动后才会解锁下一步；不方便操作可跳过。

## 5. 右键菜单

### 18. 实操：右键菜单

右击伙伴身体，查看菜单；点击菜单外空白处收起。本步仅练习打开菜单，菜单中的业务操作暂时禁用。

## 6. 动作轮盘

### 19. 实操：动作轮盘

在伙伴身体按鼠标中键，打开轮盘后选择一个动作。轮盘会避开屏幕边缘；选中动作才算完成。

## 7. 点击互动

### 20. 实操：单击互动

单击伙伴的头或身体，稍等摸头或轻戳动画出现。单击与双击区分，双击打开快聊不计入本步。

## 8. 双击快聊

### 21. 实操：双击快速对话

在伙伴身体快速双击鼠标左键，打开快速对话。本步仅预览，发送与录音暂时禁用；可以用右上角关闭。关闭后再次打开会新建空白对话，不带上一次上下文；旧记录可从完整对话的“快速对话”分组打开。

## 9. 对话模型

### 22. 新增文字服务商

点击“新增”，选择你的服务商。没有账号可跳过本章；取消选择不会删除已填内容。一个服务商可保存多个模型，当前模型只能选择一个。

### 23. 文字服务连接

展开连接设置，核对 API 基础地址和协议，填写本服务的 Key；允许匿名的自建服务可留空。需要代理时再开启并确认本地代理已运行。这里的代理与更新下载线路分开。密钥在本地加密保存。

局域网自搭中转可填写 `http://192.168.1.50:3000/v1` 等内网 IP 地址，保留实际端口和路径；不需要鉴权的内网服务可留空 API Key。具体填写方式见 [局域网自搭中转](dialogue-setup.md#局域网自搭中转)。

### 24. 添加与选择模型

点击「保存并获取模型列表」，再将需要的模型加入已配置列表；查不到时可手动填写完整模型 ID。获取列表会访问服务，只证明列表接口可用，仍需后续真实聊天测试。

### 25. 模型容量与能力

在模型编辑器核对上下文 Token 容量、工具调用和图片能力，再选为当前模型。容量未知可保留 0 使用工作设置的兜底值；能力声明不代表接口及账户已通过测试。切换不会自动发送草稿。

### 26. 是否使用流式回复

开启后文字逐段显示；有些兼容接口仅支持非流式，遇到空回复或协议错误时可关闭重试。

### 27. 保存文字配置

“保存并继续”只保存文字服务这一页，不会连带保存尚未完成的识别、朗读或 Live 配置。

### 28. 验证一次真实文字请求

点击下方按钮发送一次简短文字测试，收到非空回复才算通过；不会读取聊天记录或录音，可能产生服务费用。401/403 查 Key 和权限，404 查地址、协议及模型，超时查网络和代理。

## 10. 语音识别

### 29. 理解语音识别

ASR 把录音转成文字，再交给对话模型，与 TTS 和 Live 不同。按需添加识别服务，并确认账户有对应权限；暂不使用可以跳过本章。

### 30. 识别服务连接

填写服务提供的 ASR 地址、专用 Key，需要时单独配置代理。预设值只是起点，请核对实际支持的识别模型；文字服务配置不会自动复用。

### 31. 填写识别模型

填写识别模型 ID。此页不获取模型列表；不要填入普通文字聊天模型。

### 32. 保存识别配置

保存本页识别设置后，需在聊天中手动点击麦克风才会录音。停止并识别会生成草稿，发送并识别会提交；Esc 取消。保存和阅读本步均不会申请麦克风或录音。

## 11. 回复朗读

### 33. 回复朗读

TTS 将回复读出。选择声音输出并调节音量，再选择 Windows 语音或云端服务。后续需要手动试听，单纯配置不会播放声音。

### 34. 选择系统朗读或云端 TTS

关闭“使用云端 TTS”：使用 Windows 系统语音，不需要云端 Key。
开启：才会使用下方云端模型与音色；仅仅添加朗读模型并不会自动启用云端 TTS。想用云端，请现在明确打开此开关。

### 35. 系统朗读路径

当前关闭云端 TTS，后续云端地址、模型、Key 步骤会自动略过。可以直接保存并测试 Windows 语音。系统缺少合适声音时，可在 Windows 语言和语音设置中安装。

### 36. 新增云端朗读服务

当前已开启云端 TTS。点击“新增”选择朗读厂商，确认账号已开通文字转语音服务。此处是朗读服务，不是语音识别，也不是 Live。

### 37. 云端朗读连接

核对 TTS 的 API 地址、接口协议及专用 Key，勿填网页、ASR 或 Live 地址；匿名自建服务可留空 Key。需要代理时单独开启并确认运行。文字聊天成功不代表 TTS 可用。

### 38. 填写云端朗读模型

确认模型 ID 是支持语音合成的模型，且账号可以调用。此页不获取模型列表，预填模型可按厂商文档修改。

### 39. 选择或输入音色

从下拉列表选择，或直接输入厂商提供的音色 ID。模型与音色必须匹配。当前伙伴、服务与模型分别保存声音偏好；推荐音色仍需实际试听确认。

### 40. 保存朗读配置

保存会记录当前引擎、云端服务与音色。保存成功只表示配置格式有效，不能证明服务能合成声音。下一步会提供显式试听。

### 41. 实测：点击测试朗读

手动点击试听，等播放成功且确实听到后勾选确认，才能记录验证。可随时停止；中止不算成功。无声时先查输出设备、音量和引擎；云端还需查地址、Key、模型与音色，可能产生费用。

## 12. Live 通话

### 42. Live 与分步语音的区别

Live 是实时语音通话，与录音转文字及 TTS 分开配置。按需添加支持的服务；暂不使用可跳过。测试只会在你主动点击后开始。

### 43. 实时语音连接

填写服务提供的完整 WSS 地址和 Live 专用 Key，需要时配置代理。确认网络允许 WebSocket；不会自动复用文字、ASR 或 TTS 配置。

### 44. 确认实时模型与 Key

填写可用的 Live 模型 ID，再填写该服务的 Key。模型预填值不保证你的账号已经开通权限。

### 45. 选择 Live 音色

选择或输入实时模型支持的音色，例如 Kore；不能把普通 TTS 的音色 ID 当作必然兼容。

### 46. 保存 Live 配置

只保存，不会连接服务或启用麦克风。之后可以从这里或聊天窗口的声波按钮显式发起通话。

### 47. 可选：连接、说话、挂断

主动点击测试才会连接并使用麦克风；实际连通后再确认，可能消耗服务额度。选择语音模式时区分 Live 实时通话与 ASR 录音识别，关闭通话即可结束。

## 13. 主动问候

### 48. 是否主动问候

按需启用主动招呼，并选择是否用 AI 生成。AI 招呼使用当前文字模型，可能产生调用费用；不启用 AI 时使用本地文案。继续本步不会发送招呼。

### 49. 设置问候间隔

填写间隔和抖动分钟数，例如 60 和 10，实际为 50–70 分钟；抖动填 0 即为固定间隔。

### 50. 预览一次问候

可以点击预览按钮查看真实问候气泡。若使用 AI 问候，预览可能请求模型；不需要时直接继续。

## 14. 快捷键与记录

### 51. 免打扰的作用

安静模式减少伙伴打扰；也可选择全屏时自动隐藏。按需设置，不需要为完成教程改动每个开关。

### 52. 穿透与锁定：先记住恢复方法

鼠标穿透会使你无法直接点击伙伴，可通过系统托盘菜单或穿透快捷键关闭；锁定位置会禁止拖动。先知道恢复入口，再开启这些选项。

### 53. 设置快捷键

点击快捷键框后按组合键，为快速对话设置快捷键；不需要时可清除。隐藏、安静模式等快捷键也在本组，可按需调整后保存。

### 54. 本地记录与导出

“保存聊天记录”控制是否继续写入本机加密历史。关闭不会自动删除已有记录。完整对话右上方可导出当前记录为 Markdown，导出文件是普通可读文本，应自行妥善保存。

## 15. 完整对话与项目

### 55. 打开真实的完整对话窗口

本章进入真实窗口，创建的分区、项目与草稿会保留。不会自动发送消息。操作失误可取消弹窗，或跳过当前练习。

### 56. 拉宽窗口，显示更多标签

拖动完整对话窗口边缘，把宽度拉大，或点击窗口标题栏的最大化。宽度足够后左侧栏才会出现；更宽时右侧工作面板也会展开。拉高窗口可显示更多侧栏记录，其余可在侧栏内滚动。请实际展开左侧栏再继续。小屏幕最大化后仍未出现时可跳过侧栏练习，通过输入框的项目选择器新建或选择项目。

### 57. 认识左侧栏

左上方“新建对话”创建空白草稿。聊天分区直接管理会话，工作分区组织项目及其下属会话；悬浮或键盘聚焦行时显示轻量操作。点击会话保持原位，拖动到条目前后可调整并保存顺序。

### 58. 实操：新建分区

在侧栏分组菜单创建一个分组，实际创建后才可继续。分组可折叠、重命名和排序，用于整理项目，不会执行模型任务。

### 59. 实操：新建项目

创建项目并选择实际目录，创建后才可继续。项目可折叠、调整顺序，并通过菜单重命名或修改目录；不会自动执行任务。

### 60. 实操：新建对话

点击左上方“新建对话”。空白草稿在首次成功提交前不会作为已保存记录出现在侧栏；关闭空草稿不会新增一条记录。请创建一个新草稿。

### 61. 实操：切到工作模式

选择「工作」，输入框上方会显示项目栏；尚未关联时显示「选择项目」。工作模式可以使用已授权工具，普通聊天用于对话；切换本身不调用模型。

### 62. 实操：选择项目

点击输入框上方“选择项目”，可搜索已有项目，选择“无项目”，也可从弹层新建项目。选择只应用于当前草稿，首次提交才保存归属。请打开选择器并选择一个已有项目，或跳过。

### 63. 检查对话模式隐藏项目栏

选择顶部“聊天”，项目栏应立即隐藏，不能从 + 或 @ 菜单选择项目。返回工作入口会恢复之前的工作会话与项目。普通聊天不需要项目。

### 64. 添加附件

+、粘贴或拖放可附加图片和文件，发送前可移除。图片识别需要当前模型支持。文件夹路径只是引用，不会自动读取整个目录，也不会扩大 Agent 权限。

### 65. 可选实测：录音并识别成草稿

保存 ASR 配置并允许 Windows 麦克风访问后，点击麦克风说一句，再用「停止并识别」生成草稿。返回非空识别文字才算通过，取消或手动输入不算。录音会发送给所选服务，可能计费；本步不会自动录音。

### 66. 发送、换行与运行中补充

默认 Enter 发送、Shift + Enter 换行，可在工作设置的编辑器分组更改。

### 67. 会话整理与导出

在侧栏会话行可置顶、归档或打开更多菜单重命名；归档只是移出常用列表。顶部「文件」菜单可导出当前会话，有记录时才启用；长列表可滚动浏览。

## 16. 工作设置

### 68. 先看工作设置的作用范围

工作设置用于下一次工作请求，保存不会开始执行任务。项目设置与无项目默认设置有不同作用范围，请先读标题下的范围说明。

### 69. 设置默认工作目录

相对路径从此目录解析。点击选择文件夹可选实际存在的目录；它不是普通聊天存放路径，也不会把已有项目自动搬走。

### 70. 选择工作审批模式

可选择请求批准、帮我批准或完全访问权限。新配置默认帮我批准：符合条件的例外由独立模型审核，无法确认时转人工。请求批准时，项目内常规文件操作可直接执行，越界与联网需确认。完全访问先征求确认，以当前账户权限执行，不会提权；MCP 与 GitHub 写入仍独立确认。旧配置沿用原有行为。

### 71. 计划模式只读

需要先分析时开启计划模式，禁止写文件和打开目录等操作。关闭后才允许执行当前实现支持的修改；停止任务不会撤销已经完成的修改。

### 72. 终端与工作区沙箱

终端默认关闭，需单独启用，不改变之前选择的审批模式。“请求批准”和“帮我批准”模式下，Agent 的终端命令均逐条人工确认，即使开启沙箱也不跳过。Windows 工作区沙箱隔离终端和子进程，项目可写，网络默认禁止；故障停止执行，不自动回退。宿主文件、网页与远程工具仍按各自权限执行。旧配置保持原行为。

### 73. 练习一次审批，不执行命令

点击下方审批练习，核对示例命令、目录、任务和调用编号，再允许或拒绝。本练习只展示真实确认窗口，不创建进程、不修改文件，不保存可复用授权，也不表示终端已经验证。可跳过。实际命令需在以后每一次请求中重新确认。

### 74. 先决定是否信任说明与技能

信任项目后可读取项目范围内的 AGENTS.md 和技能；附加目录读取顶层 SKILL.md，额外说明需为 UTF-8 文件。它们不能扩大权限或自动运行脚本，添加后需保存。

### 75. 保留修改前备份

建议开启自动备份。完整访问时备份在原文件旁的 .deskpet-agent-backups；受限工作目录时备份位于项目中。文件已被外部更改时会检查冲突，不应无条件覆盖。

### 76. 目标与上下文

目标用于补充后续任务要求，保存不会运行任务。上下文预算按所选模型容量估算并预留输出和工具空间；接近上限时自动摘要，失败会停止请求。未知容量在后续步骤设置兜底值。

### 77. 仅未知容量使用兜底值

只有当前模型没有可用容量时才出现兜底值。按实际模型能力填写 Token 上限，不要填得高于服务能力；更换为已知容量模型后会自动使用其容量。

### 78. 界面与输入偏好

「对话与输入」集中设置执行详情展开、消息预测、纯文本编辑和上下文指示。预测可能产生额外模型请求，建议只填入草稿；隐藏上下文指示不关闭自动压缩。按需修改并在本页保存。

### 79. 发送与跟进方式

在「对话与输入」选择 Enter 或 Ctrl+Enter 发送及生成期间的排队/跟进方式，保存后生效。组合输入期间不提交；跟进在可接入边界生效，不会撤销已执行的操作，明确停止需用停止按钮。

### 80. 确认当前 Agent 能力边界

当前桌面端支持已接入的文件与目录工具、搜索和文件修改。不能把模型文字里的“已运行”当作执行证据。终端需单独启用并遵循审批与沙箱设置，MCP 必须主动连接，子任务只读，GitHub 需配置实际仓库且写入按次确认。未开放的工具不会因为提示词而获得。

### 81. 以执行证据核对结果

以文件变更、退出码和执行日志核对结果；中断后先检查外部状态，避免盲目重放破坏性操作。只读 explore worker 按队列运行、继承权限限制并单独计费，不能写文件或执行命令；停止父任务也会停止它们。

### 82. 项目事实由你手动维护

任务面板的项目事实可手动新增、编辑和删除，保留来源任务／文件与时间；仅供同项目后续任务引用。删除后不再注入。不会自动沉淀长期记忆，也不会从模型结论推断验证成功。

### 83. 保存工作设置

点击“保存并继续”验证目录、兜底值等并保存。本步不执行文件工具。保存失败时停留在这里，可以修正或跳过。

### 84. 单独配置工作提示词

切换到“工作提示词”标签。所有桌宠与项目的工作模式共用它；普通聊天仍使用各自人格。提示词不能扩大文件权限，也不能启用未接入的工具。

### 85. 保存工作提示词

可保留默认值，或填写自己的工作风格与结果要求。不能为空。“保存并继续”只保存此标签的工作提示词，不覆盖前面尚未保存的其他设置。

### 86. 网页搜索（可选）

在“设置 → 工具与连接 → 网页搜索”选择提供商并保存。原生搜索需要当前模型和接口支持；独立服务和自定义接口分别配置，可能另行计费。本步骤不会自动开启或发起搜索。

### 87. 可选：连接你信任的 MCP 服务器

MCP 位于主窗口左侧「插件」中的 MCP 页面。按需添加可信服务器；保存不等于连接成功，须手动连接后查看状态。stdio 连接可能启动本地程序，请先核对命令与权限。本步骤不会自动连接。

### 88. MCP 协议与凭证

选择支持的 stdio 或 HTTP 协议。HTTP 填 HTTPS 地址和独立凭证；stdio 核对程序路径、JSON 参数、环境及目录，勿把密钥放入命令行。保存只保存配置，须之后手动连接核对状态。

HTTP 凭证在本地加密保存，与对话模型的密钥分别配置。

### 89. 主动连接，再查看真实状态

只有主动点击连接才访问服务器或启动 stdio。连接成功后，新任务才会获得实际工具目录；未知操作按次确认，窗口列出服务器、目标、原始操作和参数。可断开以移除工具并结束本次拥有的 stdio 进程。无服务器可直接跳过，不会标为连接已验证。
