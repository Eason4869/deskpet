# 对话、附件和原生 Agent

适用于 0.6.1 源码及 Agent 增强开发分支。Windows 提供完整文件 Agent；Mac 预览支持聊天、Markdown、附件及过程展示，暂不提供本地文件工具或应用窗口快照。

## 对话界面

四位内置伙伴使用独立圆角头像，角色菜单、设置、对话、引导与 Live 共用同一资源。按钮悬停和键盘焦点使用浅灰圆角底色；发送／停止主按钮保留蓝色。对话输入框始终白底，聚焦时不叠加灰色背景；空输入框保留预设文字，输入后隐藏。已发送图片和文件显示为文字气泡上方的独立卡片。滚动条为无箭头的细灰色圆角滑块，悬停／拖动时变深色。

快速对话显示最近的用户消息与 AI 回复，完整对话保留历史加载和导出。用户消息使用右对齐的浅蓝气泡，最大为消息区的一半；AI 正文直接排版。两者支持标题、强调、删除线、列表、任务列表、引用、表格、链接、行内代码和代码块，流式未闭合的代码块也可显示。Markdown 中的图片以链接显示，上传的图片另有缩略图；不执行 HTML。

模型实际返回的思考说明使用黑色，原生工具摘要使用灰色，默认不展开全部细节。开始正式回答后自动隐藏过程。回答完成后在下一行显示复制、朗读、更多图标。复制保留原始 Markdown，朗读读取正文纯文本；更多可重新生成、复制纯文本、导出单条 Markdown、重新查看思考和工具记录。不能展示服务商未返回的思考内容，也不会为不支持思考的模型伪造内容。

过程预览默认只显示“思考中／处理中／编辑中／运行中”等固定状态，不将模型长句放入折叠标题。平时不显示展开箭头，悬停时在文字末尾出现灰色“>”，点击整行展开／收起详情；正式结果开始时自动隐藏。用户已发送消息的复制图标和本地发送时间默认隐藏，悬停在消息上时显示，复制保留 Markdown 原文。

每次 AI 请求顶部显示实时耗时：对话模式为“思考时间”，工作模式为“处理时间”。从本轮请求开始计时，包含模型输出过程，完成、失败或取消后冻结；耗时与发送时的模式随聊天记录保存，重新生成会重新计时。旧记录没有计时数据时不补造耗时。

## 输入框左下角 +

1. **文件和文件夹**：直接打开系统选择器，选择图片、PDF、Word/Excel 文档或常见 UTF-8／带 BOM 的文字和代码文件；Windows 可用“添加当前文件夹”加入正在浏览的目录。目录作为引用附件，不批量上传其内容，也不改变工作目录与权限；选取范围不受工作目录限制。
2. **附加应用快照**：直接显示其他应用中最上层的合格窗口及其应用图标；没有其他可见、未最小化的普通应用窗口时置灰。点击后获取一次 PNG，加入待发送卡片。不会自动发送，也不会失败后改截整个桌面。不支持窗口内受保护视频等内容，失败会明确提示。
3. **目标**：保存后随之后的工作模式请求携带，清空即可取消；保存目标本身不会发起模型请求，也不会后台持续消耗额度。
4. **计划模式**：模型只能读、搜索和分析；写入和修改工具同时从协议列表移除，并在执行层拒绝调用。关闭后从下一次请求恢复可写。

文件和图片统一支持三种添加方式：**Ctrl+V 粘贴、+ 选择、拖入对话窗口**。剪贴板截图会转换成 PNG；普通文字仍按原生文字编辑器粘贴。输入框的中文右键菜单提供剪切、复制、粘贴和全选，复用原有快捷键与撤销逻辑。

附件以图片缩略图／文件卡片显示，右上角 × 移除。最多四个附件，单次总大小不超过 4 MB，单个文字附件最多 10 万字符。文字文件与 Word/Excel 文档转为文字（.docx/.xlsx 内置解析；.doc/.xls 需要本机 Word/Excel 或 WPS），图片及 PDF 使用模型原生输入。图片和 PDF 需要所选模型与服务商支持。文件发送、排队与恢复都使用选取时的内容快照；原文件后来移动或删除不影响已排队附件。

## 对话模式与工作模式

**完整对话默认工作模式**，启用原生文件 Agent；也可点击 + 右侧的模式按钮切回带聊天气泡图标的**对话模式**，只聊天，不提供本地文件工具，不应用工作目标或计划指令。**快速对话始终为纯聊天**，不显示模式切换，顶部以“快速对话”标注；从快速对话发起的请求即使完整对话处于工作模式，也按纯对话发送，且不改变全局模式。在完整对话输入框中按无修饰的 **Tab** 可在两种模式间切换，**Shift+Tab** 保留焦点导航。切换对下一次请求生效，不会改变已开始的任务。

## 工作设置

详细设置依次为伙伴、模型配置、工作设置、快捷键、关于。“工作设置”包含：

1. **访问权限**：默认完整访问，可操作当前 Windows 用户有权限访问的本地目录，包括桌面、文档及其他磁盘；也可切换为仅限工作目录。不会提升系统权限。
2. **默认工作目录**：更改或重置相对路径的起点；完整访问下不作为路径边界。
3. **计划模式**：共享 + 菜单开关，只读分析，禁止写入、新建和打开目录。
4. **持续目标**：共享 + 菜单目标，保存不会启动请求。
5. **修改前备份**：默认开启，可打开备份位置；完整访问下备份位于被修改文件所在目录的 `.deskpet-agent-backups`，受限模式则集中在工作目录下。
6. **上下文预算**：默认 32768 tokens，可设 8192–131072。接近预算时自动压缩旧输出和历史，保留目标、最新要求及完整的近期工具组；应根据模型实际窗口设置预算。任务不再设置总轮数或总时长上限，可手动停止。
7. **项目命令**：默认关闭。开启后配置命令名称、程序完整路径、每行一个参数及超时；保存时绑定当前项目。保存设置只保存授权，不会执行命令。
8. **展开过程详情**：默认关闭；正式结果开始输出时仍自动隐藏过程。
9. **显示预测消息（Windows）**：默认关闭。根据最近的完整文字对话请求下一条用户消息预测，产生额外模型请求。输入框为空时在其内部以浅色 ghost 文本显示首条预测；第一次 Enter 仅填入草稿，释放按键后再次 Enter 才发送；按住 Enter 不会越过确认直接发送（每次物理按键只执行一个动作）。Shift+Enter 换行；直接输入会覆盖预测；按 Esc 关闭预测，本轮回复内不再出现。输入、排队或工作开始时取消预测。

## 内核、MCP、Provider 与子 Agent

项目/会话切换复用同一个聊天窗口实例，后台 workspace、历史、队列和草稿按会话隔离。项目名称在项目设置中编辑；对话首次完成后由当前文本模型生成短标题，手动重命名后不再自动覆盖。项目和对话标题完整换行显示，右键菜单支持重命名；左侧项目标签支持折叠、计数、活动状态和独立滚动；展开/收起使用开合文件夹图标。项目和对话右键支持重命名、归档、恢复和永久删除。链接在输入预览、用户消息和 AI 输出中使用统一的可点击样式；文件卡片支持打开、打开方式、资源管理器、复制路径/内容和另存为。完整对话的原生 Agent 使用自研 C# 内核组合 Codex CLI 与 OpenCode CLI 的能力边界，不复制第三方源码。会话具有稳定项目/会话/输入/步骤 ID；排队输入幂等，历史、检查点和上下文压缩事件可恢复。工具调用保留模型 CallId，执行前后记录权限、结果、耗时和任务归属，输出有界且支持取消。

模型能力描述包括上下文窗口、工具、流式、推理、图片和音频。当前 Provider 不支持工具时，工具不会出现在请求 Schema 中；`build`、`plan`、`explore`、`general` Profile 分别约束主执行、只读规划和子 Agent。子 Agent 具有排队、并发上限、启动、中断、完成与失败生命周期，排队提升不会改变其 ID。

MCP 只通过统一工具注册表接入，支持 HTTP JSON-RPC 与 stdio JSON-RPC。stdio 会执行 `initialize`/`notifications/initialized`、`tools/list`、`tools/call`，按 JSON Schema 生成工具参数，拒绝非法工具名和重名覆盖，并在工作区销毁时结束进程。MCP 工具仍受 `mcp` 权限、计划模式和审计约束；未经允许的 MCP 工具不会执行。
## Windows 原生文件 Agent

默认工作目录是程序目录下的 `data/agent-workspace`，通过设置 → 工作设置改变。每次请求固定一份设置，运行过程中切换模型或计划模式不会改变正在执行的任务。

提供分页目录列表、glob 查找、带文件筛选与正则超时的内容搜索、至多 8 文件批量读取，以及原有读写和目录工具。`apply_patch` 支持至多 20 文件的精确修改或新建。支持新建文件、新建文件夹和用资源管理器打开目录。完整访问遵循 Windows 用户权限；受限模式把路径限定在工作目录。拒绝设备路径、符号链接、junction 和外部硬链接。写入为原子替换，可保留修改前备份。另有 `list_changes`、`restore_file`、`update_plan`、`list_commands`、`run_command` 和 `read_output`；没有任意 Shell、文件删除或鼠标键盘自动化工具。

读写支持 UTF-8 文字，文件最多 1 MiB；.docx/.xlsx 用内置 OOXML 解析与生成：读取返回文档／表格文字，写入按文字生成真实文档（每行一段、# 标题、** 加粗；表格用制表符或逗号分列，支持引号转义），文档最大 8 MiB、表格最多 5000 行×64 列；.doc/.xls 通过本机 Word/Excel 或 WPS 的 COM 转换，未安装时给出改用 .docx/.xlsx 的提示。Word/Excel 文档支持 read_file/read_files/write_file 与 search_files 检索，不支持 old_text 精确修改，需用 write_file 完整重写；restore_file 按字节恢复原始文档。单次补丁参数最多 128 Ki 字符，其他工具参数最多 32 Ki 字符，因此较大文件应分段精确修改。任务持续到完成、手动停止或出现错误，不设总轮数、总调用次数和总时长限制。仍保留单次请求、工具批次、单条命令超时、文件及输出等资源边界。停止后不再执行后续调用；已完成的写入及备份会保留。模型需要支持 OpenAI 或 Anthropic 原生工具协议；不兼容时可以切换回对话模式。

**多轮 Agent 会产生多次模型请求，按所选服务商规则计费；附件及工具读出的内容会发送给该服务商。**

当前原生文件工具与应用快照仅支持 Windows。Mac 保留普通聊天、Markdown、附件、目标和计划说明，工作模式入口不可用；选择文件夹只附目录引用，不提供本地文件读写或窗口捕获，也不会因保存目标而启动任务。

原生协议设计、固定开源参考与验证边界见 [原生 Agent 实现](native-agent-design.md)。

## 代码任务的实际操作

1. 在现有输入框选择工作模式，在“工作设置”选择项目目录；需要验证时启用项目命令并保存命令配置。
2. 发送任务。Agent 可查找文件、批量读取、记录计划并修改相关文件。默认窗口在聊天顶部提供可折叠任务详情，原有布局与输入方式保持一致；窗口宽度达到 960 时显示左侧项目与任务导航，达到 1280 时增加右侧浮动任务/变更/验证详情卡；最大化与手动拉大采用同一规则，中间保留对话和输入区。屏幕不足以容纳三栏时，任务详情保留在对话中；恢复窗口会收回侧栏并保留草稿。快聊通过“任务详情”打开完整对话。
3. 展开“文件变更”可并排查看修改前备份与当前文件。预览每侧最多 12000 字符，不是逐行差异算法；若已有后续改动，会显示提示。“恢复”仅在当前文件仍匹配任务修改结果、且原备份校验通过时生效。新建文件没有原备份，不提供自动删除。
4. “命令与验证”显示真实命令名称、退出码、耗时、停止或超时状态及输出。没有运行命令时明确显示“尚未运行构建或测试验证”。
5. 停止或退出后已完成修改保留。检查点按伙伴和项目加密保存；重新打开不会自动重放操作。点击“继续任务”才会发起新的模型请求，并要求先核对当前项目。清除任务记录仅清除检查点，不删除项目文件和备份。

命令只能引用用户设置中预先配置、绑定当前项目的 ID。项目内脚本和依赖仍以当前 Windows 账户运行，工作目录并非操作系统沙箱。单条命令默认 120 秒，可设 1–600 秒；停止、超时与命令退出均清理该命令的子进程。stdout/stderr 持续排空，保留合计最后 256 Ki 字符；模型先收到至多 12000 字符预览，可按需分段读取剩余输出。非 UTF-8 输出可能出现替换字符。

普通聊天记录与任务检查点分别保存；关闭聊天历史保存不会关闭任务恢复。检查点保存失败会在界面和更新检查中提示；处理目录权限或空间后，可点击任务详情中的“重试保存”，不发起模型请求。每次模型请求前检查上下文预算；先压缩较早工具输出，再按完整协议组生成模型摘要与任务事实。压缩时对话显示“正在压缩，请稍后”，完成后原位显示“上下文已自动压缩”。保留的调用 ID、结果及协议思考签名不拆散；摘要失败会明确标记并保留任务事实，必要时重新读取文件。输出归档有界，过旧或被截断的内容需要重新读取。

单个任务最多保留 256 条文件变更记录；达到上限后拒绝新增变更，保留现有恢复记录。多文件补丁会在写入前检查数量限制和父路径冲突。

## 不打断工作的引导

忙碌时普通发送进入队列，按顺序处理。Ctrl+Enter 或队列“引导”把补充要求加入待接入区；当前工具或命令完成后，在下一次模型请求前接入，沿用同一任务及变更记录。接入前保留在加密队列，停止或退出不会把待接入消息当成已完成。发送菜单中的“停止并立即发送”用于确实需要强制中断的情况。

## 变更摘要

工作任务结束后，在对应回复下显示实际文件列表及可获得的增删行数；先显示三个文件，可展开其余文件。行数根据原始备份与当前结果计算，无法可靠计算时不显示估计数字。“查看变更”打开真实前后内容；任务详情提供逐文件恢复，并拒绝覆盖任务之后的外部修改。
工作过程中，输入框正上方用一行显示已更改文件数和可获得的真实增删行数，不展示估算数字。任务结束后该行收起，回复下方保留变更卡。
