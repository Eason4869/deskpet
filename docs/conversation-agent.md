# 对话与工作说明（Windows 0.9.3）

## 会话和项目

快速对话和普通对话使用当前伙伴的人格、上下文及个人记录。关闭快速窗口后重新打开会创建空白新会话；旧记录仍在该伙伴的“快速对话”分组。完整窗口的普通聊天保存在“默认分区”或指定聊天分区，不选择项目；只有快速窗口创建的记录保存在“快速对话”。

工作模式共享项目、工作记录和工作提示词。在新草稿上方选择项目，也可以使用“无项目”。切回对话模式时隐藏项目选择；切换模式不自动发送草稿。工作提示词在工作设置的单独标签页中编辑，不会替换普通聊天的人格。

完整窗口拉宽或最大化后显示左侧导航，更宽时显示右侧任务面板。聊天分区直接显示会话，工作分区组织项目；两种模式均支持新建、重命名分区。“快速对话”“最近”等固定分组可展开、收起和改名。“最近”汇总当前伙伴的普通及快速聊天。点击不会自动改变会话位置，拖动到条目前后调整并保存顺序；工作会话可拖到其他项目名称，普通聊天可拖到其他聊天分区标题。对话支持置顶、归档、重命名、导出及永久删除；删除前使用应用内确认。

## 输入、附件与跟进

输入区默认直接编辑排版后的 Markdown。在工作设置的编辑器分组开启“纯文本编辑器”，可保留原始语法；只影响输入方式，发送后的消息仍支持 Markdown。默认 Enter 发送、Shift + Enter 换行，可改为 Ctrl + Enter 发送、Enter 换行。

预测消息默认开启，可能额外请求文字模型；预测先进入草稿，不自动发送，可关闭。输入框为空且显示预测时，普通 Enter 先确认预测；释放后再按一次才提交。

通过 +、粘贴或拖放添加图片、文本、Word/Excel 文件或目录引用，发送前可移除。目录引用不自动读取整个目录，也不扩大权限。应用窗口快照仅在 Windows 可用，需要明确选择；不能把它当作自动桌面监控。

运行中可按默认方式排队或引导，Ctrl + Enter 使用相反方式。排队在本轮结束后处理；引导保持当前操作及任务，在下一处可调整的模型或工具边界接入新要求。已发出的 HTTP 请求不能中途追加输入，未开始的旧工具计划会跳过并交给模型重新规划。已完成的文件修改不会自动撤销。“停止并立即发送”是单独的主动中断操作。

## 工作设置

| 设置 | 作用 |
| --- | --- |
| 工作目录 | 相对路径起点；受限访问时作为文件边界 |
| 文件访问范围 | 完整访问遵守当前 Windows 账户权限；仅工作目录限制工具访问，不提权 |
| 计划模式 | 只读与分析，禁止写入和打开目录等副作用 |
| 修改前备份 | 默认开启，保留原文件；恢复前检查后续改动 |
| 持续目标 | 为下一次请求补充目标，保存不会启动任务 |
| 上下文管理 | 优先使用模型配置的容量；未知时使用兜底值，预留输出与工具空间并自动整理旧历史 |
| 编辑器 | 预测消息、纯文本、上下文用量、发送快捷键、默认跟进方式 |
| 工作提示词 | 全部工作对话共享，独立于各伙伴人格 |

项目设置覆盖该项目的工作字段；编辑器和过程显示属于全局偏好，在项目页只读。隐藏上下文用量只隐藏指示器，不会关闭自动压缩。估算用量不等于服务端精确计费。

## 当前桌面 Agent 可以做什么

Windows 原生 Agent 支持分页目录、文件查找、内容搜索、批量读取，以及文本的创建、写入、精确替换和多文件补丁；支持创建和打开目录、计划记录、查看变更与恢复原文件。模型需要支持 OpenAI 或 Anthropic 原生工具协议。

原子写入、修改前备份与冲突检查保护已有文件。拒绝不支持的设备路径、链接路径等越界访问；“仅工作目录”是文件工具访问限制，不是操作系统进程沙箱。完整访问也不授予管理员权限。

.docx/.xlsx 使用内置文档读写能力；.doc/.xls 需要本机 Office 或 WPS 转换，缺少时请改用现代格式。文档写入由文字内容生成，不保证保留复杂版式；文档不使用文本 old_text 精确替换。恢复按原始备份进行，新建文件没有原备份，不提供自动删除。

当前产品不提供通用终端、项目命令配置、桌面点击或键盘自动化。MCP 和子 Agent 底层接口不代表桌面已经接通连接管理或自动执行；GitHub 读取取决于实际配置，写入缺少确认入口时不开放。工具只报告实际发生的动作，不能把模型回答中的“已运行”当作构建或测试证据。

## 任务与恢复

文件变更面板可查看原备份与当前文件，恢复前核对当前内容，避免覆盖其他程序的修改。停止、关闭窗口或取消请求后，已完成的修改和备份保留。重开工作区会恢复已保存的状态，但不会自动重放工具副作用；继续任务才会发起新请求。

会话按稳定 ID 保存，历史、草稿、队列和任务属于各自会话。损坏或无法解密的记录不会由新请求静默覆盖，存储失败显示原因。关闭聊天历史时不继续持久化本轮会话输入；此前已有文件不会因此自动删除。

接近可用上下文时自动压缩，保留当前要求及完整工具协议组；摘要可能额外调用模型。单次文件、请求、工具输出及执行批次仍有资源上限，不表示可以无限读取文件。

发送给模型的文本、附件和工具结果会传给所选服务商，多轮工具执行可能产生多次计费请求。请按实际工作内容选择服务与权限。

## 平台范围

上述新版 Windows 界面及原生文件 Agent 不代表 macOS 预览已经同步。Mac 当前保留聊天、Markdown 显示、附件、语音及共享核心能力；不提供本地文件 Agent 或应用窗口快照。

逐步操作见 [配置引导](configuration-guide.md)，模型与语音连接见 [模型配置](dialogue-setup.md)。
