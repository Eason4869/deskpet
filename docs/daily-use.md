# 日常使用

## 初次见面与设置

首次启动先配置 GitHub 加速、选择伙伴，再明确选择是否在后台下载和更新全量官方角色包；可同时继续后续引导。Windows 引导共 17 章、132 个小步骤，可配置伙伴、模型、听写、云端朗读、Live、分区项目与工作设置；支持返回、跳过及断点继续。完整流程见 [配置引导](configuration-guide.md)。进入更高主／次版本系列时自动打开一次，同系列补丁不重复，之后仍可手动重开。

普通聊天与快速对话跟随各自伙伴，工作项目和工作记录共享。关闭快速窗口后再次打开是新会话，旧记录仍在该伙伴的快速对话分组。完整窗口普通聊天进入“默认分区”或指定聊天分区，不进入“快速对话”；工作模式草稿显示项目栏。两种模式均支持新建、重命名分区，聊天分区没有项目文件夹。会话点击后保持位置，可通过拖动调整并保存顺序。更多说明见 [对话与工作](conversation-agent.md)。

伙伴内可配置人格、陪伴方式与主动问候；模型配置分别管理文字、语音识别、声音与朗读、Live。工作设置独立管理文件访问、项目目标、上下文、编辑器及共用工作提示词。

## 和伙伴互动

按住角色拖动时，伙伴会悬空并轻轻晃动；松开后落地。单击头部是摸摸头，单击身体是戳一戳；双击仍打开快速对话。单击动作会稍等系统双击间隔，以免把双击误当成两次互动。

右键 → 互动提供摸摸头、戳一戳、喂零食、小憩和两项具名招牌动作。投喂后伙伴会开心回应；小憩期间不散步、不主动问候，点击“叫醒”或开始其他互动即可唤醒。这些互动无需 AI，也不会自动播放语音。

| 伙伴 | 原有招牌动作 | 新增招牌动作 |
| --- | --- | --- |
| E包 | 傲娇扭头 | 比心鼓励 |
| 大肥鱼 | 摇尾欢呼 | 泡泡环游 |
| 马尔芙 | 挥杖流光 | 荧光咒语 |
| 小贝 | 太极光环 | 全息键盘 |
| 咕嘎 | 咕嘎摇摇 | 转圈摆鳍 |

支持踉跄动作的伙伴在实际拖动并松开后，有 40% 概率短暂踉跄，完成后回到待机；触发后冷却 10 秒。普通点击、未实际移动、暂停或配置引导中不触发，重新拖动、切换伙伴、隐藏或开始聊天可中断。设置 → 伙伴 → 陪伴方式可关闭。自定义外观缺少新增素材时保持普通落地。

四位伙伴的四项技能、投喂后开心、拎起、普通落地及踉跄均参照原画逐条重绘；E包跳跃也已重绘。每条 8 个关键姿态，以 8 FPS 按顺序播放；迟到的界面刷新会延长当前姿态，不追赶跳帧，也不混帧。统一整组比例与定位，清除背景及边缘色溢；未重绘的基础动作继续沿用原有节奏。

0.5.6 同时保留新旧两套互动：喂食、小憩、两项专属每次随机一套，喂食后的开心沿用本次版本；小憩可能坐着，也可能站着。拖起时决定新旧版本，普通落地和踉跄沿用同一套；松手后共用 0.3 秒的小段下落，按宠物大小等比例缩放并受屏幕底部限制，拎起不额外上抬。旧素材保留原有姿态数量，按 8 FPS 播放，不复制新姿态。

“偶尔散步”现改为每次等待 90～180 秒再尝试，互动后重新等待；步速与距离不变。

默认开启空闲小憩：系统键鼠空闲 5 分钟，或 15 分钟没有直接操作伙伴后，每分钟以 70% 概率进入小憩。鼠标仅在其他应用活动，不会重置“未操作伙伴”的计时；直接操作伙伴或手动唤醒会重新计时。聊天、听写、Live、排队任务、拖动、动作、引导、菜单、设置或更新倒计时期间不触发；隐藏和暂停时也不触发。可在“陪伴方式”关闭，不调用 AI。

**中键点击角色**打开动作轮盘。每项以当前伙伴的缩略图展示，下方有简短名称，悬停可看说明：

- **技能**：喂零食、小憩／叫醒、伙伴的两项具名招牌动作；有第二招牌动作时使用四等分轮盘，缺少该动作的自定义外观显示三项。
- **动作**：待机、向右跑、向左跑、招呼、跳跃、委屈、等待、思考、检查成果。

选择后播放并收起。轮盘缝隙等宽，中心可切换技能／动作；滚轮切换分类，方向键选中后按 Enter 播放。中心关闭按钮、再次按中键、Esc 或点击外部均可收起。左右跑会实际移动一小段，到屏幕边缘停止；锁定位置时原地演示。摸头、戳身体、拖拎和落地直接通过鼠标手势触发，不放入面板；开心是投喂后的自然回应。右键菜单仍可照常使用。伙伴思考或工作时仍可互动；开始拖动、暂停或切换动作会停止手动跑动。

锁定位置时仍可单击互动，但不能拖动。暂停动画时不响应单击和拖动动画；主动选择菜单动作可恢复播放。自定义外观继续使用原来的动作格式，互动采用已有动作回应。

## 快速对话、朗读与 Live

双击伙伴打开快速对话，默认 Enter 发送、Shift + Enter 换行，发送快捷键可在工作设置中修改。从快速对话展开可在完整窗口查看该会话；关闭快速窗口后再次打开会创建新会话，旧记录保留。

输入框右侧有两个主要按钮：简约麦克风“听写”，以及蓝底白色主按钮。主按钮有文字时始终显示发送箭头；无文字且 AI 忙碌时可以选择默认排队或引导，运行中 Ctrl + Enter 使用相反方式。排队等待本轮结束，引导继续当前操作，在下一处可调整的工具或模型请求边界接入补充要求，并重新规划未执行的步骤；已经发出的模型请求不能热插入内容。需要中断后重发时，明确选择“停止并立即发送”。

AI 忙碌时，发送默认加入队列，按顺序逐条回复。输入框上方的紧凑列表可直接“引导”、删除或点击铅笔编辑。发送选项中的“打断并发送”（Ctrl + Enter）会停止当前回复，优先发送新消息，再继续原队列；引导某条排队消息也是同样规则。打断后会带上原问题及明确标记为未完成的输出，供下一次请求理解补充要求。

停止或请求失败会暂停队列，保留未发送内容；失败消息也保留，可编辑或删除后点击“继续队列”。编辑时暂缓后续发送，不停止当前回复。队列保存在对应会话的本机数据中，使用当前 Windows 用户加密，与聊天历史开关独立；重启后恢复为暂停，须手动继续。每个队列最多排队 20 条，每条最多 8000 字。

点击“听写”后，输入区显示真实收音波形，右侧两个按钮切换为黑色停止图标和黑底白色箭头。点击“停止听写”会结束并识别，文字追加到原草稿，供编辑；点击“发送听写”会识别后连同原草稿发送，AI 忙碌时加入队列。两种方式都不会丢弃原有草稿。Esc 或隐藏／关闭录音窗口可取消听写；达到 60 秒时自动结束并填入草稿，不自动发送。听写可以和 AI 回复同时进行，Live 通话期间不可开启。

左上角缩略图旁的小喇叭控制 TTS 自动朗读，快速对话、完整聊天和设置中的“TTS 输出”同步。关闭会停止当前朗读，也会跳过还在生成中的回复朗读，文字仍然显示。音色按伙伴和服务模型保存，切换角色后随之切换。

点击快速对话或完整聊天中的 空闲且输入为空时的 **通话声波按钮**，会在当前窗口内显示通话界面并尝试连接。连接成功后才打开麦克风；头像周围的环形波形随真实收音和回复音量变化，字幕显示当前发言。点击挂断、返回文字对话或关闭通话窗口可结束。连接失败可进入 AI 配置调整，再重新连接。TTS 喇叭不控制 Live 原生音频。

悬停在宠物可见身体上时，从跳跃、打招呼和两项具名招牌动作中等概率选择一项；一次移入只尝试一次。停留期间暂停视线跟随，移出宠物窗口后恢复原跟随设置，再次移入才能触发下一次。动画变换不会重复触发。引导、拖动、对话、菜单或轮盘操作期间不触发。

穿着万圣节服饰时，悬停还有机会触发伙伴专属彩蛋。节日期间完整播放结束并保存成功后可永久收藏这套服饰，首次收藏后在伙伴设置下方显示“特殊服饰”。自动换装、选择服饰和普通动作不会直接解锁，详细规则见 [节日服饰](holiday-outfits.md)。

中键轮盘以调用时的光标为中心显示，靠近屏幕边缘时限制在可用区域内。

## 自动更新

设置 → 关于 → 检查并更新：发现所选通道的更高版本后自动下载并校验，在安全空闲后倒计时 5 秒，保存状态、退出、覆盖安装并重启。无需手动退出桌宠。下载和倒计时期间可取消；点击“立即更新并重启”会跳过剩余倒计时，但仍等待任务、草稿及数据保存。

可选择正式版（main）或预览版（dev）：正式通道只取正式版，预览通道取两者中的最高版本。切换仅保存选择，不立即下载；更新进行中不能切换。版本始终递增，同底版先按 dev 序号递增，再到正式版。若切回正式通道而正式版较旧，会继续使用当前版本。

“网络加速”默认收起，展开后可选择一种连接方式：

- **不使用 GitHub 加速**：直接检查版本和下载更新，新配置默认使用此项。
- **使用 GitHub 加速**：从多个内置镜像中单选，或填写自定义 HTTPS 镜像地址，先点击“测试连通性”，查看每个地址的可用状态和读取文件头耗时，再选择通过测试的地址；自定义地址也需先测试。内置地址按长度从短到长排列。仅加速更新包下载，版本信息和校验值仍从 GitHub 官方获取；镜像下载失败或校验不符时回退 GitHub 直连，更新区域显示实际通道。
- **使用网络代理**：检查版本和下载均使用填写的 HTTP 代理，默认 `http://127.0.0.1:7890`。已有用户的代理选择与地址会保留。

内置地址包括 `https://gh-proxy.org`（默认）、`https://gh-proxy.com`、`https://edgeone.gh-proxy.com`、`https://hk.gh-proxy.com`；地址选择保存后重开仍会恢复，第三方节点可用性以“测试连通性”的实际结果为准。默认镜像按 [GH-Proxy 官方文档](https://gh-proxy.com/docs/github-accelerator)的地址前缀格式配置。连通测试仅读取更新包的一小部分，不执行安装；最终下载仍需完整长度与 SHA-256 校验。更新的网络选择不会改变文字、听写或 Live 服务各自的代理设置。

关于页固定底栏的“卸载”（无需滚动）会打开当前安装目录对应的卸载向导并退出桌宠，保留 `data` 中的设置、聊天记录、排队消息与外观。便携运行目录显示手动移除说明，不调用其他安装目录的卸载程序。

未发送的文字（包括隐藏窗口中的输入）、排队消息、未保存设置、进行中的对话或听写会让安装等待。手动更新可自动关闭空闲聊天和设置窗口；后台更新则等这些窗口关闭后再开始。配置、聊天记录和导入外观保留。

聊天记录保存失败时也会暂停安装，先导出重要记录或处理保存问题，再继续更新。引导或动作轮盘开启时，关闭面板后再等待自动安装。更新交接前会再次检查活动状态并等待历史写入。

## 聊天历史

设置中可选择是否保存聊天历史，默认开启。普通聊天记录属于各自伙伴，工作记录跨伙伴共享；完整窗口可加载更早消息或导出 Markdown。永久删除只清理选中的会话，确认前请先备份需要的内容。

每个会话的历史与队列保存在对应数据目录，Windows 使用当前账户保护。停止、异常或 Live 中断保留未完成状态，不伪装为成功回复。引导不会标记为中断，详见 [对话与工作](conversation-agent.md)。关闭保存不自动删除先前文件，存储损坏时保留原记录并显示原因；导出的 Markdown 是普通文本。

## 流式回复

设置 → AI 配置 → 文字模型 → 流式回复，默认开启，需点击“保存服务设置”。快速对话和完整聊天共享同一条回复，文字逐步增长；生成期间打开另一窗口可接着查看。向上阅读历史时不强制滚回底部。

点击停止会取消当前请求；断线或服务错误保留已有文字并显示状态。未完成回复不自动朗读，不作为完整的下一轮模型上下文。接口明确不支持流式时可关闭开关。程序不因流式失败自动发送第二次请求。文字完成后按 TTS 偏好与免打扰状态决定是否朗读。

## 免打扰与桌面行为

免打扰暂停主动问候、散步、自动朗读，并停止当前自动朗读；不修改 TTS 输出开关和音量。主动文字、录音及 Live 可继续使用。

全屏自动隐藏默认开启，只检测伙伴所在屏幕的前台全屏应用。退出全屏时仅恢复自动隐藏的伙伴；手动隐藏一直保留。主动唤出快速对话可暂时覆盖全屏隐藏。隐藏时不渲染动画，定时恢复检测仍运行。

整体鼠标穿透让点击落到下方应用，聊天窗口仍可操作；从托盘或快捷键关闭。锁定位置禁止拖动与散步。托盘常用开关与设置同步保存。

## 主动问候

进入 **设置 → 伙伴 → 主动问候**，可开关问候、调整随机间隔和预览气泡。默认每 30–60 分钟使用角色预设台词打招呼，不调用模型。伙伴使用与自身身份相符的预设问候；自定义导入伙伴使用通用预设和自己的名字。

**使用 AI 生成主动问候** 默认关闭。开启后，每次问候使用当前选中的文字服务与真实模型 ID，以及当前伙伴最近 4 轮已完成聊天；每条记录最多取 600 字。当前的记忆来源就是聊天记录，不会读另一位伙伴的记录、桌面或文件。切换聊天模型后，之后的问候使用新模型；生成中的旧请求会取消。

AI 问候可能消耗模型额度。未配置、请求失败、超过 8 秒、回复过长或与近期问候重复时，自动改用角色预设，不弹出服务错误。生成结果与预设都不写入聊天历史，也不自动朗读。可在问候页点“预览问候气泡”试用当前选择；只有明确打开 AI 开关才会发模型请求。

聊天、语音、队列处理、互动、小憩、全屏和隐藏时保持安静。短暂忙碌打断尚未显示的自动问候时，只保留一次延后尝试；暂停、免打扰、关闭开关、换伙伴或退出会丢弃迟到结果。每位伙伴会避开最近显示过的 8 条问候。

## 伙伴、动画与模型切换

预设伙伴包括 E包、大肥鱼、马尔芙和小贝。小贝是道士服少年，专属动作是“太极光环”；在伙伴设置或右键外观菜单中即可选择。每位伙伴分别保留人格与聊天记录。

预设动画使用低帧率原画直接换帧，不混合相邻姿势。开启视线跟随后，鼠标移动时显示对应的真实方向；停止约 1.4 秒后回待机，再次移动时恢复跟随。

“AI 配置 → 文字模型”可以保存多个服务商与各自的模型列表，模型显示名支持中文。快速对话和完整聊天的输入框右下角都可切换模型；菜单按服务商分组，悬停可查看真实 ID。相同显示名不会合并不同服务商的模型，实际请求仍使用对应的原始模型 ID。新选择从下一条请求生效，正在生成的回复继续使用开始时的配置。

待发送队列的每行前方显示排队图标，悬停该行时出现六点拖拽柄。按住柄拖动，半透明消息跟随光标，其他行让出位置，松开后按新顺序发送。只排序尚未发送的消息；仍可使用原有编辑、引导和删除操作。键盘聚焦拖拽柄后可用 Alt + 上／下调整顺序。
