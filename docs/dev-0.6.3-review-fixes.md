# 0.6.3 本地审查修复（未发布）

> 历史审查记录：以下本地状态、版本及测量对应 0.6.3 预览阶段。相关修改现整合进 0.7.0；当前功能及交付状态见 README 与 CHANGELOG。

基线：dev `a2f91dd`。本次仅在本地 `codex/fix-dev-063-review` 修复，不创建 Release、不推送分支或标签。

## 修复内容

1. 输入区的计划模式、目标与项目请求使用同一套有效配置。任务面板、重新生成和会话队列跟随当前项目，计划模式在工具层拒绝写入。
2. 移动对话时重新绑定项目目录、权限、目标和内核身份；忙碌中的任务必须先停止，避免运行中切换写入目标。
3. 对话数据改用 `data/conversations/<conversationId>`，与所属项目无关。首次打开自动迁移旧 `data/projects/<projectId>/chats/<conversationId>`；对话已移动的旧数据也按唯一 ID 找回。检测到重复旧目录时保留原件并拒绝猜测。
4. `.session` 使用当前平台的 SecretProtection 加密并原子保存。兼容旧明文记录，成功加密后移除旧文件；关闭历史时不持久化内核输入，清空聊天同步清空内核输入和事件。
5. 内核保存失败显示存储告警，操作结束仍释放忙碌状态，可修复目录后重新发送。损坏或无法解密的旧记录不被新模型覆盖，明确清除后才能恢复保存。
6. 重开对话加载已保存的内核 Step、Pending、Delivered 和事件。运行中状态恢复为 interrupted，不自动重放工具副作用。
7. 子 Agent 中断会终结执行声明并为同一父任务补位；完成其他父任务时不会错误提升并超出并发上限。
8. 创建项目弹窗参考用户提供的布局：明确标题、名称输入、源文件夹面板，以及底部“取消”和深色“创建项目”按钮。操作栏单独预留空间；长路径在面板内滚动，校验提示不挤出按钮。

## 后续界面和交互调整

- 侧栏支持新建、重命名分区，项目可通过菜单或拖放进入分区。快速聊天保存在“聊天 / 默认项目”；该默认项目初始折叠，其他项目初始展开。归档区域默认折叠。
- 项目不再常驻高亮。当前对话浅灰选中；运行中显示旋转圆环，后台完成后显示未读蓝点，进入对话即清除，并保存状态。
- 新建完整对话先作为草稿，支持搜索、选择项目或不选项目。首次发送被队列接受后才登记归属；配置校验失败保留输入，不留下空对话。无项目对话显示于“最近”，可拖入项目。“最近”的项目归属过滤选项持久保存。
- 关闭快速聊天窗口后，再次打开创建新对话；展开当前快速聊天进入完整窗口时保留当前内容。
- `/`、`@` 菜单采用分组、图标和说明，支持搜索、键盘选择与滚动；禁用无法执行的项目。鼠标或键盘执行均只移除触发片段，保留其余草稿。
- 删除聊天窗口右上角清空按钮，保留导出。创建、编辑项目与重命名聊天统一为圆角弹窗，保留取消、保存与关闭；编辑项目可修改源文件夹，并进入独立工作设置。移除项目仍需确认，不删除工作目录中的源文件。
- 模型配置首次打开显示空服务商列表。连接区域隐藏“当前模型 ID”，模型列表支持搜索、逐个点击 + 添加及自定义模型弹窗；移除复选框、全选和批量添加。
- 模型容量按服务商和模型分别保存。自动读取兼容模型目录的 `context_length`、`context_window` 等字段；未提供则标为未知，不根据名称猜测。支持 1024–2000000 Token 手动覆盖，覆盖值优先，切换模型不会沿用前一模型容量。
- 模型选择左侧显示上下文圆环，提示估算用量、容量、百分比及自动压缩预算。工作模式使用实际待请求体估算，普通对话使用待发送历史；不是服务端精确计费数值。
- 普通对话也接入发送前自动压缩；保留当前请求、必要历史和附件。工作模式继续保留工具调用与结果的协议组。摘要服务失败使用明确标记的事实回退，不虚构摘要。压缩预算取用户预算与已知模型容量的较小值，预留输出空间，取消会终止压缩。
- 移除公共窗口样式的永久最大高度限制，只约束初始窗口大小。最大化交由系统根据当前显示器工作区处理，保留任务栏。
- 针对测试中复现的“无法删除要被替换的文件”，共享原子保存加入对短暂文件占用的有限重试，读取时允许原子替换。持续占用仍保留原文件并报告失败，不先删除原记录。后台自动标题保存失败不会弹出阻塞对话框。
