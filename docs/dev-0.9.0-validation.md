# 0.9.0 dev 提交前审核与验证

日期：2026-10-19。基线为 `ae8f032`（0.8.0 dev）。本批包含统一窗口、权限和沙箱、工具标签、技能、用量统计、图片预览、引导及桌宠跑动。

## 最终审核

独立审查分别覆盖 UI 与生命周期、权限与终端隔离、统计与文件交付及插件。确认的问题已修正：

- GitHub 读取和搜索原先未进入新审批模式的联网确认；现在与其他联网操作一致，Legacy 与完全访问行为保留。新增授权测试先失败，修复后通过。
- 浏览器关闭后临时 profile 未清理；现在在浏览器进程退出后回收自有 profile，启动时保守清理过期且未占用的自有根目录。删除前核验绝对父目录、所有权标记、GUID 名称、租约与重解析点。
- 模型列表获取在缺少同步上下文时从后台线程更新 WPF；Windows 事件记录明确为 Dispatcher.VerifyAccess 异常。成功、错误和加载状态清理均已回到所属 Dispatcher，仅忽略已确认关闭时的派发取消，CTS 始终释放。
- 引导的权限说明仍指向旧版禁用控件；稳定步骤 ID 不变，改为真实三档审批控件，导出说明同步到文件菜单。
- 离线引导、README 新文档和安装器收录项同步，避免源码、便携包和安装版内容不同。

独立复核未发现剩余已确认的重要阻塞项。此前切换会话的 Popup 问题以所有权及连续切换回归验证；没有把该验证描述为精确复现全部历史运行异常。
