# 模型、听写、朗读与 Live 配置

Windows 0.7 的完整逐步说明见 [配置引导](configuration-guide.md)，包含 17 章、118 个小步骤。首次使用可以跳过暂时不需要的服务，之后从设置左下角继续。

## 文字模型

1. 打开设置中的“模型配置 → 文字模型”，点击新增服务商，选择厂商或自定义接口。
2. 确认服务地址与协议，填入 API Key；需要本机代理时单独开启“使用代理连接”。
3. 点击保存并获取模型列表。在候选模型右侧逐个点击 + 添加，没有多选框。
4. 获取失败时，可手动添加服务商提供的完整模型 ID；已配置模型不会因列表失败被清空。
5. 按服务商实际能力设置上下文容量，并按需要填写中文显示名；显示名只用于界面，请求仍使用原模型 ID。
6. 选中要使用的模型，保存配置。切换服务商或页面会保留未保存草稿，切换伙伴前应先保存。

支持 OpenAI Chat Completions 与 Anthropic 兼容文字协议。列表可见不代表模型一定适合文字或工具调用，实际能力取决于厂商和账号。候选列表不会自动全部加入配置。

聊天输入框可切换已配置的服务商与模型。正在运行的请求使用其原始配置，后续请求才采用新选择。

## 听写：把语音转成输入

在“语音识别”添加服务商，确认预填模型、地址、密钥和代理并保存。这里使用独立配置，不会因为文字模型可用而自动配好。

点击聊天输入框的麦克风才开始录音。停止按钮将识别结果填入草稿，发送按钮识别后提交，Esc 取消。设备不可用时按提示检查系统麦克风权限和默认输入设备。

## 回复朗读：先选择引擎

只使用 Windows 系统语音时，无需云端 TTS 服务；在朗读页选择可用音色并测试。

如需云端 TTS：

1. 在“声音与朗读”明确开启云端朗读。
2. 添加或选择朗读服务商，填写该服务的 API Key，确认地址、协议、模型及代理。
3. 选择音色或手动填写服务商提供的 Voice ID。音色按伙伴与服务模型保存，模型兼容性以服务商为准。
4. 先保存，再点击测试朗读；确认能听到声音后，开启回复朗读。
5. 音量默认 50%，可以即时调整。关闭对话头像旁的喇叭开关可停止当前朗读并跳过后续自动朗读，文字回复保留。

若测试无声，依次检查系统输出设备、音量与静音、音色 ID、模型权限及网络；不要只凭保存成功判断连接可用。音色参考见 [音色预设](voice-presets.md)。

## Live：独立的连续语音通话

Live 使用独立的 Gemini Live 连接与音色。配置好相应服务后明确点击测试或通话，连接成功后才打开麦克风。挂断或关闭通话窗口会停止收音，并返回原页面。

Live 原生音频由通话本身控制，普通回复的 TTS 喇叭开关不替代挂断。真实麦克风授权、网络及声音效果需在自己的设备上确认。

## 代理、密钥与费用

每项服务分别保存地址、密钥与代理。代理默认地址为 `http://127.0.0.1:7890`，只有本机确实有该代理服务时才启用；关闭后直接连接。支持 HTTP 代理，不接受 SOCKS、带账号或带路径的代理地址。

同一个厂商也可能对聊天、识别、TTS 与 Live 使用不同接口和权限，请分别核对。保存和列出模型不等于已经成功完成对话、识别或朗读测试。

Windows 密钥按当前账户保护。使用云端功能会将相应文字、音频、图片或文件内容发送给所选服务商，并按其规则计费。预测消息也可能产生额外文字请求，可在工作设置的编辑器分组关闭。

## 人格与工作提示词

普通聊天使用各伙伴自己的可编辑人格，记忆与记录独立。工作模式使用“工作设置 → 工作提示词”的共用内容，工作项目和记录跨伙伴共享。提示词不会扩大文件权限，也不会启用尚未接入的工具。详见 [对话与工作](conversation-agent.md)。
