# 安装、升级与自启

Windows 10/11 x64，需 .NET Framework 4.8 或更新版本。下载来自 [GitHub Releases](https://github.com/Eason4869/deskpet/releases/latest)。

当前正式版本为 **0.9.1**，Windows 安装包为 **DeskPet-Windows-Setup-0.9.1.exe**，免安装包为 **DeskPet-Windows-0.9.1.zip**。同一发布页提供 macOS Apple Silicon 与 Intel 预览包，未经 Developer ID 签名或公证；Mac 功能与 Windows 存在差异，下载时请核对架构及 preview 标记。

## 安装

运行所下载正式版本的 **DeskPet-Windows-Setup-版本号.exe**，按中文向导安装到当前用户目录，首次安装默认 `%LOCALAPPDATA%\Programs\EbaoDeskPet`。不要求管理员权限；可选桌面快捷方式，开始菜单有启动和卸载入口。已有安装沿用原目录，保留原有 `data`。

首次使用默认 E包，还可切换大肥鱼、马尔芙与小贝，无需另外导入。首次启动会打开 17 章、131 个小步骤的配置引导，逐项填写与实操；支持跳过本步、本章和稍后继续，重开时恢复进度。设置左下方“配置引导”可重开。进入更高的主／次版本系列会重置并自动打开一次，同系列补丁升级不触发；已完成、跳过或关闭后不重复，降级不降低记录。旧配置缺少记录时按 0.5 系列迁移。

安装包没有默认开启自启，也不会调用模型或打开麦克风。自启在设置 → 伙伴 → 陪伴方式 → **开启自启** 中选择；开关立即应用于当前程序路径，关闭后撤销。移动程序文件夹后，请在新位置重新开启自启。

## 升级

0.3.1 将软件名统一为“桌面伙伴”，仓库改为 `Eason4869/deskpet`。从 1.3.x 调整版本编号后，旧版的数字比较不会提示这个较小的版本号，请手动下载最新正式 Release 的安装包安装一次。安装器保留原应用标识和安装目录，迁移本目录已经开启的自启到 `桌面伙伴.exe`，移除旧名称 EXE 和旧名称快捷方式；`data` 保留。新安装默认不开启自启。

免安装版请完整解压到新目录后复制旧版 `data`，或覆盖原目录。旧版开启了自启时，请在新版重新开启，以绑定新的 EXE 名称。不要再从旧名称 EXE 启动。

设置 → 关于 → **检查并更新** 可自动完成下载、SHA256 与长度校验、退出桌宠、覆盖安装和重启，无需手动退出。默认启动 30 秒后自动检查，每 4 小时检查一次，失败后 10 分钟重试，可关闭。下载期间及重启前的 5 秒倒计时可取消；后台更新会在桌宠旁显示倒计时和取消按钮，不抢输入焦点。未发送文字（包括隐藏窗口中的草稿）、进行中的对话或语音、全屏、拖动、未保存设置或聊天记录保存失败会让安装等待；手动更新可自动关闭空闲的聊天与设置窗口，后台更新则等窗口关闭。引导、动作轮盘或窗口内 Live 通话打开时也会等待；历史保存失败请先导出重要记录或处理保存问题，更新交接前会再次等待历史写入完成。

安装版根据本安装位置的记录，在原目录静默升级；便携版使用运行 ZIP 替换发行文件，不修改其他安装记录。专用助手等待旧进程退出后执行，不重启 Windows。配置、密钥、导入外观及其他 `data` 保留；便携替换失败恢复原文件并重新打开原版。更新结果显示在关于页，任务包和备份在 `data/updates`。0.4.0 起聊天记录默认按伙伴加密保存，重启后恢复；可在设置中关闭保存。

**0.9.1 提供正式 Windows Release 与安装包，并附 macOS 双架构预览。** 更新器只检查正式 Release，单独的 dev tag 不触发更新。Windows 更新只接受规范命名的 Windows 运行包，不会选取 Mac、Linux、源码或外观包。

**0.5.4 及更早正式版本的安装版，无法直接通过内置更新升级到 0.6.0 及后续版本。**0.5.6 安装包保留 `DeskPet-Setup-0.5.6.exe` 旧名；从 0.6.0 开始安装包统一为 `DeskPet-Windows-Setup-版本.exe`，免安装包仍为 `DeskPet-Windows-版本.zip`。0.5.6 程序与更新助手已支持新名。请先手动安装 0.5.6 后使用内置更新，或直接手动覆盖安装最新版，保留原 `data`。便携 ZIP 名称与目录布局保持兼容，不受安装包改名限制。旧 1.x.x-beta 用户也需手动安装完成编号调整。

首次从免安装版迁移：退出原桌宠，将原文件夹的 `data` 复制到新安装目录（首次启动前）。密钥由当前 Windows 用户加密，换用户或机器需重新填写。

## 卸载与备份

使用 Windows 的“已安装的应用”或开始菜单卸载入口。卸载移除程序、快捷方式和指向本安装目录的自启项，保留 `data`。需要彻底清除个人配置时，在确认不再需要后自行删除安装目录中的 `data`；备份则复制该文件夹。

使用正式 Release 中的 **DeskPet-Windows-版本号.zip** Windows 免安装包时：完整解压到可写目录，运行桌面伙伴.exe。请保留 docs、templates 和 previews 文件夹。免安装版自启绑定解压位置。

安装包当前未做应用代码签名。发布页附 SHA256 校验文件；自动更新要求固定仓库、匹配的版本与附件名称、完整长度及 GitHub 提供的 SHA256 摘要。无法验证时保留原版，提示到 Release 页面查看。

## 旧版更新兼容性

0.4.0 便携包曾包含旧更新助手不支持的 GIF 预览，表现为下载、重启后仍是旧版本。0.4.1 已恢复兼容运行包，可从 0.3.3 直接更新。GitHub README 保留动画，本地文档使用静态图。
