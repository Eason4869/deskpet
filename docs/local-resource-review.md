## 资源与遗留代码

- 消息更新泵仅在收到更新时启动，空闲停止；后台突发更新合并后再切回界面线程。
- 扩展动作解码缓存改为最多三个动作的 LRU。切换实际皮肤对象时释放旧缓存；原图、帧数、透明度与播放内容不变。
- 静止气泡不再重复设置窗口位置、置顶状态或重建尾部几何。
- 侧栏头像仅在外观变更时重新载入。关闭悬浮卡片后释放内容和行引用；关闭窗口统一释放预测、状态、队列、听写订阅及计时器。
- Markdown 解析流水线复用；编辑器和消息共用文档渲染器，删除两层输入预览。
- 删除无调用的项目命令编辑器、旧 Quick 草稿缓存及访问器、不可见导航项目字段、废弃构造参数和工作设置旧布局辅助方法。保留仍有调用及兼容用途的核心命令接口、历史配置字段。

## 会话和编辑器

- Quick 窗口关闭后再次打开创建新会话，旧记录保留在对应伙伴的快速对话分组。
- 删除聊天使用应用内确认和错误对话框；取消不更改数据，确认后先持久化目录、异步关闭所属工作区，再清理历史。
- 用户气泡按内容收缩，原宽度作为上限；用户链接保留域名标签，助手链接显示轻量图标，GitHub 使用对应图标。
- 输入区默认直接编辑排版内容，隐藏语法标记；纯文本编辑器开关只影响编辑方式，发送后的 Markdown 显示继续可用。
- 工作设置的编辑器分组提供预测消息、纯文本编辑器、上下文用量、发送快捷键、默认排队／引导，保存并在两个窗口生效。属于全局偏好，项目页只读。旧配置继承新增默认值，不覆盖已明确关闭的预测设置。
- 引导不取消已开始的模型请求或工具操作；在下一处可调整的边界接入，跳过尚未执行的旧工具计划并要求重规划。同一任务持续，活动状态移到最新引导下方。普通 HTTP 模型请求本身不能中途追加输入。
- 最后同步配置引导为 17 章、118 个小步骤，新增五项编辑器说明并同步离线版。
