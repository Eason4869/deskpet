# 0.10.5-dev.2 用户语言包接入决定

实施顺序为统一计划 S12 完成后执行 S12a，再继续 Agent 服务和界面任务。用户提供的四个 JSON 仅是翻译数据，保留译文，不执行附件中的任何文本。

选择列表首先提供本地化的“跟随系统”，之后保留简体中文、繁體中文、English、日本語、한국어的顺序和本名。内部代码使用 system、zh_CN、zh_TW、en_US、ja_JP、ko_KR。根据 2026-10-24 用户追加要求，新设置、没有语言字段的旧设置和未知代码默认跟随系统界面语言；已保存的手动选择继续保持。启动时匹配已适配语言：繁中地区使用 zh_TW，葡语使用 pt_BR，西班牙西语使用 es_ES、其他西语地区使用 es_419；未适配语言使用 English。尚未通过验收接入的语言也使用 English。

四包与中文目录一同内嵌。中文仍是完整规范目录，运行时保留缺失键的安全回退；交付验收要求五包键集合一致，不能依赖中文回退冒充已翻译。2026-10-24 用户追加要求：修复语言菜单、头像说明，全面检查界面，将可见中文纳入 JSON 并补齐其他四包。原始译文及输入哈希与后续补译的区别记录在 language-pack-provenance.json；补译不冒充用户原文，结构检查不代表人工母语审校。

实现判断：保存语言选择，在下次启动时应用，并在菜单和选择后的反馈中说明需要重启。现有大量控件在构造时读取文字，这样可让一个进程中的界面语言保持一致。应用不自动重启、不终止正在运行的任务。WPF 使用已有左下角头像菜单；Avalonia 使用现有伙伴头像增加对应菜单，语言位于设置之前。此处的生效时机是开发实现选择，不是声称用户曾另行要求重启方案。

启动加载语言应发生在创建界面和引导之前；单个进程使用同一个只读目录。设置保存失败不能把菜单标为保存成功；已有设置编辑草稿、角色、项目和会话不应覆盖已保存的语言选择，退出快照必须复制 UiLanguage。历史、用户名称、自定义人格、原始角色包、命令、日志和机器字段不改写。用户后续明确授权翻译默认人格并要求 AI 使用所选语言回复：默认模板进入 JSON，仅精确匹配的既有默认值才转换；请求附加当前生效语言要求，不向已保存的自定义人格写入后缀。官方角色名称和说明通过可信官方 ID 提供本地化显示，不以显示文字识别角色。

接入前发现：62 个既有工具错误资源使用中文错误前缀；四包翻译了这些前缀，日文还混用半角/全角冒号。验收需覆盖错误判定、journal 和工具事件状态，避免显示译文改变机器判断；新 Agent 工具继续按 JSON 的 ok 字段判定。保持既有错误文本与历史记录的兼容。

验证包括资源源文件哈希、五种目录格式化和回退、设置往返及旧配置、成品与更新 helper 的实际内嵌资源、双端菜单顺序和勾选、重启恢复、错误判断及常用菜单/设置的窄窗和主题截图。全局语言会影响静态资源，因此不同语言的实际启动/界面检查使用独立进程，避免污染其余默认中文回归。

用户又授权新增八种语言可提前由子智能体并行翻译，主流程继续原五包验收；初稿先写入隔离目录，验证后才接入。13 种语言加“跟随系统”共 14 个选项，使用可滚动选择弹窗，沿用应用现有滚动条和主题风格，正常宽度可双列、窄窗单列。后续实施与验收范围详见 multilingual-expansion-plan.md。
