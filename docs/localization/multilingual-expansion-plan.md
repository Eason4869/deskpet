# 0.10.5-dev.2 多语言补齐与扩展

2026-10-24 用户追加需求覆盖原 S12a 中“缺词回退、不补译”的范围限制；S12 已通过本地工具/会话阶段验收。实现仍在临时分支及草稿 PR，尚未授权合并、打 tag 或发包。

执行顺序：

1. 先验证简体、繁体、英文、日文、韩文。补齐所有缺词，将遗漏的用户可见中文移入 JSON；区分界面文案与已保存的用户内容、提供商参数及稳定身份。包括头像副标题、角色显示名/描述、品牌显示、音色描述、快捷键标题的启动初始化顺序。修复截图发现的截断，并重跑受影响页面。
2. 用户后续明确允许子智能体提前并行翻译新增八包：fr_FR、de_DE、hi_IN、id_ID、it_IT、pt_BR、es_419、es_ES。译稿先写入隔离目录，主流程继续原五包验收；验证后再接入。按语言负责 JSON 翻译，保留格式参数、协议字段、URL、代码和标识符。新语言不以整段英文或中文复制充数。
3. 总计 13 种语言，加“跟随系统”共 14 个选项。默认跟随系统界面语言，保留已保存的手动选择；繁中地区匹配繁中，葡语匹配巴西葡语，西语区分西班牙和拉美，未适配语言回退 English。将头像菜单入口改为可滚动的选择弹窗，使用语言本名、明确选中状态和保存反馈。正常宽度可双列，窄窗单列；沿用应用现有滚动条和主题资源，验证悬停、拖动、键盘选择、浅深色及窄窗。保留现有五个语言名称：简体中文、繁體中文、English、日本語、한국어。
4. 默认人格提示词进入 JSON 并随实际生效语言调整；精确识别默认模板，保留自定义人格和角色归属。普通聊天、Agent、实时语音和问候的请求明确要求使用当前生效语言回复。更换语言不覆盖用户自定义内容；待重启的语言选择与本进程生效语言区分。
   - 翻译审查发现系统朗读仍优先选择中文音色，错误文案也建议安装中文语音。扩展语言接入时一并修正：优先匹配实际生效语言的系统音色，没有匹配时使用系统默认；提示安装相应语言语音，保持云服务音色参数和自定义配置。
5. 每包键集合与中文规范目录一致、无重复/空值、格式占位符一致；分别验证 Framework/.NET 实际读取及应用/helper/Core 成品资源。不同语言使用独立进程，以捕获读取设置前初始化的静态文字问题。
6. 保存界面 PNG、可见文字清单、截图覆盖与未覆盖状态，检查设置全部分类、菜单、常用弹窗、引导、图像和工作入口。无截图的平台/系统对话框、真实联网及语音状态不标为通过；不以生成图片或结构检查冒充全面人工审校。

本增量之后继续 S13–S17 的 Agent 应用服务、双端界面、退出与整体验收。新增后台文案应同步进入全部语言包，避免此阶段通过后重新引入中文回退。
