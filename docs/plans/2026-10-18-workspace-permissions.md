# 工作区权限与隔离实施计划

用户已批准推荐方案并要求连续实施。0.8.0 / ae8f032 为已推送 dev 的前置快照；后续实现保留在 codex/workspace-approval-sandbox，不推送、不发布、不替换预览。

目标：三档审批、独立工作区沙箱、会话级 / 切换、旧设置保持原行为。采用原生 AppContainer 隔离执行器，保留多模型运行链；兼容性验证失败时禁止以无隔离回退冒充成功。自动审批采用确定规则和独立只读审核，异常转人工。

- [x] 原生隔离：扩展 WindowsCommandRunner 启动属性；单次 AppContainer 身份、项目权限、临时目录及清理。真实 PowerShell 验证区内读写、区外读写、子进程、联网、超时、取消。实际测试仅操作自有目录；产品对明确选择的项目设置并撤回专属身份 ACE，宿主记录目录永久停止继承容器授权。
- [x] 权限模型：Legacy / Ask / Auto / Full，Sandbox 开关；设置、项目、会话保存与复制；旧值保持 ConfirmEach/Disabled，计划模式和只读子任务为上限，审批绑定参数与权限版本。
- [x] 审核执行：边界内直行，例外走人工或独立审核，未知操作转人工；拒绝不能自动重试。沙箱故障阻止执行；MCP/GitHub 单独处理。关闭沙箱的任意命令保守审批。
- [x] UI：工作设置三档及自定义、沙箱/终端开关，输入区状态；本地 /permissions、/sandbox；扩大权限确认，忙碌时先停止才能切换；会话覆盖独立，项目保存提供默认。
- [x] 验证：新测试先失败再通过、受影响回归、共享构建、实际 WPF 交互截图、真实隔离矩阵、独立审查、报告和独立本地构建。

审查重点：权限复制遗漏、等待中权限变化、子进程/重解析点、ACL 撤回并行、无隔离误标、远程 MCP 边界、旧配置不能静默扩大权限。模型连接不随终端离线开关禁用。

用户追加并批准：顶部「聊天｜工作」双入口，独立过滤侧栏、保留各自草稿与会话，后台工作继续并提供状态；移除 Tab 和 / 中聊天/工作切换；原输入框模式入口改成「更改权限」入口，按参考图提供三档菜单；预测建议以 Tab 或 Enter 接受，Tab 不再切模式。沿用现有白底、浅灰、字体、图标及圆角，不重做数据层。

0.8.0 版本同步、Windows App 构建、2 项发布命名与 14 项 Mac 打包契约通过；dev/tag 原子推送完成，没有发布工作流。后续结果记录在 docs/workspace-permissions-validation.md。

## 同窗口工具与统一标签

- [x] 左下 + 打开真实 ConPTY 终端；新建标签页支持文件、终端、网页、临时聊天和变更详情，快捷键为 Ctrl + Shift + B。各工具保留打开时的项目背景，主会话切换不结束已有终端。
- [x] 提供分屏与完整标签视图。分屏时主聊天在左、工具在右；完整视图将原主聊天固定为首个不可关闭的标签，显示当前会话标题。使用切换按钮、Ctrl + Shift + F 或持续向左拖动分隔线进入完整视图；窄窗口自动使用完整视图，拉宽后恢复此前布局。
- [x] 切换布局保留主 Session、输入框、草稿、阅读位置和最近工具选择；隐藏／显示标签页保留工具实例及运行状态。从侧栏打开当前聊天、其他聊天或新建对话时，显示对应的主聊天。
