## 后续第一批：Agent 后台任务

**交付：** `start_job / get_job / stop_job`，支持构建、测试和本地预览，按稳定任务 ID 查看运行状态与增量日志。

- [ ] 复用已有终端开关、工作目录限制和权限审批；任务只能停止自身创建的进程树。
- [ ] 日志分页、容量与保留期限有界，任务超时可控，关闭应用有明确处理策略。
- [ ] 重启后恢复任务记录，不自动重跑命令；端口 / 预览地址与退出码可查看。
- [ ] 验收：长任务保持聊天可用；读取多页日志无丢失 / 无限增长；取消停止完整子进程树；不能越权停止其他程序。

先在现有具备本地 Agent 执行能力的入口接入；其他平台明确显示能力范围，不把共享协议支持当作原生执行能力。

## 后续第二批：模型管理与诊断

**交付：** 一个生图服务管理多个模型，按模型选择参数和能力；提供可分享的脱敏诊断结果。

- [ ] 多模型增删、当前模型、可选显示名与默认参数持久化，复用同一服务的加密连接配置。
- [ ] 能力分为已确认支持 / 不支持 / 未确认；自定义模型不只根据名称猜测协议或编辑能力。
- [ ] 区分配置错误、鉴权、限流、服务 5xx、下载和本地保存失败；诊断不泄露 Key、授权头、代理凭据或参考图字节。
- [ ] 获取模型列表不等同于实际出图验证；测试生成仍由用户明确触发，不静默切换协议或重试收费请求。
- [ ] 验收：旧单模型配置迁移保留原值；多个模型可切换；错误报告可定位阶段并通过凭据泄漏检查。

## 后续第三批：对话连续改图

**交付：** 用户可引用上一张生成图片继续编辑，保留原图及修改版本，结果进入同一图库与任务中心。

- [ ] 工具使用资产 ID 和当前会话授权上下文，支持“修改这张”等明确指代；多图时与当前选中图对齐。
- [ ] 按服务真实能力区分通用编辑和人物主体参考；不把 MiniMax 人物参考视为通用编辑。
- [ ] 新结果使用独立 ID 并记录父图 / 参考图关系，不覆盖原图；取消、失败与重试遵循任务中心规则。
- [ ] 父图与共享参考图参与图库引用保护，可查看版本关系并另存任意版本。
- [ ] 验收：连续两次修改仍能查看原图；选中不同缩略图时引用准确；跨会话误用、缺失参考图与不支持协议有清晰反馈。
