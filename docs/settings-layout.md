# 设置分类与保存方式

主要分类依次为 **伙伴、模型配置、对话与输入、工作与权限、工具与连接、通用**。“关于与更新”固定在侧栏底部。保留分类内部的顶部标签页；“对话与输入”在 Windows 版分为对话默认值、输入行为、回复与显示三个实际页面，切换页面不会丢失草稿。

| 分类 | 内容 |
| --- | --- |
| 伙伴 | 外观与人设、陪伴方式、主动问候与桌面观察 |
| 模型配置 | 对话与图片模型、语音识别、语音合成、实时语音 |
| 对话与输入 | 全局默认模式、发送和跟进方式、预测与编辑器、朗读及回复显示 |
| 工作与权限 | 默认或项目目录、目标、审批、沙箱、终端、备份、工作提示词 |
| 工具与连接 | 网页搜索、消息渠道；技能与 MCP 保留在应用左侧插件入口 |
| 通用 | 主题与界面语言、窗口行为、全局快捷键、数据与缓存 |

工作页顶部区分全局默认值与当前项目。项目的“使用全局默认值”会把当前全局配置复制到草稿，保持项目名称和工作目录；确认保存后才生效。它不是持续自动继承关系。权限变化继续经过现有确认与审批，不会因移动页面而放宽。

对话设置、工作设置和网页搜索使用固定底部保存与还原。对话设置只提交本次实际修改的字段，避免把页面打开后在聊天中切换的模式或朗读偏好覆盖回旧值。应用运行、主题等即时保存的设置有明确说明；需要单独保存的快捷键、连接或语音名称仍使用各自的保存入口。

归档对话移到“设置 → 通用 → 数据管理 → 已归档的对话”，可查看、恢复和管理历史记录。应用最左侧的主页、图片、统计、插件和设置主导航保留原样。旧导航、配置引导及工作页归档调用保留兼容。

设置搜索可定位网页搜索、输入行为、工作权限、高级沙箱参数、模型连接、语言和数据操作等具体项目。定位时切换到相应标签、展开相关高级项、滚入视野并短暂高亮；不会自动开启开关或执行清理。

布局保留原顶部标签样式；内容使用细边框圆角分组，组间距约 36px，标题到卡片 12px，设置标题和说明位于左侧、控件位于右侧。窄窗口保留紧凑导航和固定保存操作。Avalonia 客户端仅展示当前实现有实际作用的偏好，不增加无效的输入开关。

设置中的折叠标题统一采用整行点击区域，文字与右侧箭头居中对齐。“说明与技能”和“能力说明”直接展开呈现全部内容，不再折叠。
