# 桌宠外观格式

0.5.6 同时支持 v1 单图外观与 v2 分动作外观，原有 v1 导入保持兼容。Release 提供 Windows 安装包、四位伙伴的通用 v2 外观包及完整创作模板。

## v2：分动作实绘动画

仓库 `templates/high-fps-v2/` 提供完整空白制作模板，也可在设置中点击“下载制作模板”，到当前版本 Release 下载 `DeskPet-Skin-Template-v2-版本.zip`。安装包和免安装 ZIP 不内附制作素材。完成全部角色画布后，进入设置 → 伙伴 → 伙伴与人格 → 导入外观，选择其中的 `pet.json`。空白模板不能直接使用；制作模板 ZIP 需先解压。

每帧固定 **480 × 520**。每个动作使用一张 8 列透明 PNG，行数为帧数除以 8 向上取整。每格都是独立绘制的完整角色，不能复制帧凑数、混合重影或光流变形；未使用格保持透明。逐格检查头发、衣服、手脚、尾巴与配件，所有动作保持原角色比例。

`pet.json` 顶层填写 `version: 2`、`format: "illustrated-atlases-v1"`、`cell_width: 480`、`cell_height: 520`、`name`、`preview`、`animations` 和 `gaze`。预览图 `preview` 为 480×520 PNG；可选简介 `description`、人格 `system_prompt`、专属动作名 `special_action` 分别最多 1000、8000、32 字。

`animations` 必须包含以下全部动作：

| 动作键 | 中文动作 |
| --- | --- |
| idle / running-right / running-left | 待机 / 向右跑 / 向左跑 |
| waving / jumping / failed | 招呼 / 跳跃 / 委屈 |
| waiting / running / review | 等待 / 思考 / 检查成果 |
| lifted / landing / petting / poked | 拎起 / 落地 / 抚摸 / 轻戳 |
| feeding / happy / sleeping / special | 喂食 / 开心 / 小憩 / 专属动作 |

每项例如 `"idle": {"file":"animations/idle.png","columns":8,"frames":32,"fps":24,"loop":true}`。`frames` 为真实帧数，范围 1–128；`fps` 为 1–60；17 组动作总帧数最多 1024。`loop` 控制循环，`idle` 必须循环。`running` 是思考，左右跑动使用另外两个键。按实际动作连续性选择播放速率和帧数；先观察低速播放时的角色比例、重心和衔接，再调整速度。作者模板可用于高帧创作，但当前预设伙伴使用低帧版本，FPS 数字不能代替连续姿势。

`gaze` 固定为 `{"file":"gaze.png","columns":4,"frames":16,"interpolation":"none","order":"clockwise-from-up"}`。视线图是 1920×2080，4列×4行，从正上方开始顺时针每 22.5° 一张完整人物。鼠标移动时显示选中的真实朝向帧，不使用混合插值；停止约 1.4 秒后回待机，再次移动时恢复跟随。

图片路径只能引用包内相对 PNG 路径，使用 `/` 分隔目录。JSON 最多 64 KiB，单 PNG 最多 25 MiB，不同素材合计最多 256 MiB。每个使用格都要同时有可见角色与透明背景；不允许外部文件、网络路径或链接。导入会检查全部动作、视线及预览，成功后复制到 `data/skins/skin-<GUID>/`，失败时保留当前伙伴。

制作步骤、尺寸表与参考网格见模板中的 `先读我.md`、`动作表.csv` 和 `guides/`。网格只作参考，导出时隐藏。检查白色、深灰和彩色背景下的所有帧，清除抠图彩边和透明杂点。

## v1：兼容单图外观

导入入口：设置 → 伙伴 → 伙伴与人格 → 导入外观。支持单个透明 PNG，或 `pet.json` 与 PNG 放在同一个文件夹。ZIP 请先解压。仅包含图片、简介和人格，无脚本执行接口。

独立模板 ZIP 的 `legacy-v1` 文件夹提供可直接导入的 `pet.json` + 大肥鱼布局示例 `spritesheet.png`、`pet.schema.json` 格式说明和 `grid-guide.svg` 动作网格示意图。界面展开“如何制作和导入桌宠”后点击“下载制作模板”取得。解压后复制对应模板文件夹，换成自己的图，填写下列字段，再导入。SVG 是制作参考图，不是可导入的 PNG。

```json
{
  "version": 1,
  "name": "我的桌宠",
  "atlas": "spritesheet.png",
  "description": "喜欢写代码的桌面伙伴",
  "system_prompt": "你是我的桌宠，一位温和俏皮的桌面伙伴。用自然的中文回答，保持简洁，如实表达不确定性。你不能直接看见用户桌面，也不会自动读取文件。"
}
```

`atlas` 填同文件夹内 PNG 的文件名；名称最长显示 32 个字符。`description` 可省略，最多 1000 字；`system_prompt` 为预设人格，可省略，最多 8000 字。缺少人格时自动生成以伙伴名称开头的通用设定。选择 `pet.json` 保留名称及人格；直接选择 PNG 时使用文件名与通用人格。图片和模板自动复制到程序旁 `data/skins/skin-<GUID>`。

“人格”页的编辑按桌宠 ID 保存，恢复预设会还原导入时的 `system_prompt`，不影响其他伙伴。切换外观同时切换其人格与内存会话，避免角色混淆。导入同一模板多次会创建不同 ID，可以分别设定。

PNG 必须是 **8 列 × 11 行**等大网格。原 v2 小图可用 1536×2288（单帧 192×208）；高清推荐 3840×5720（单帧 480×520），采用同一角色比例。每帧需要透明背景和可见角色；未使用格保持透明。

| 行（从 1 开始） | 动作 | 有效帧数 |
| --- | --- | --- |
| 1 | 待机 idle | 6 |
| 2 | 向右跑 running-right | 8 |
| 3 | 向左跑 running-left | 8 |
| 4 | 招呼 waving | 4 |
| 5 | 跳跃 jumping | 5 |
| 6 | 委屈 failed | 8 |
| 7 | 等待 waiting | 6 |
| 8 | 思考 running | 6 |
| 9 | 检查成果 review | 6 |
| 10 | 视线 0° 至 157.5° | 8 |
| 11 | 视线 180° 至 337.5° | 8 |

视线角度从正上方开始，顺时针每格 22.5°；90° 朝屏幕右侧，180° 向下，270° 朝屏幕左侧。动作从左到右按播放顺序排列，同组人物比例与地面位置保持一致；跳跃保留实际抬升。画布留出足够边距，头发、手脚及尾巴完整。

文件限 25 MB；单帧宽 64–768、高 64–832 像素，总图限 5500 万像素。尺寸上限用于有界解码；显示比例按 192:208 的标准画布设计。损坏图、缺帧、无透明背景和路径越界会拒绝导入，当前桌宠继续使用。

源码接口：`SkinCatalog.Import(path)` → `SkinDefinition`；`SkinDefinition.Load()` → `SpriteAtlas`；`PetWindow.SelectSkin(skin)` 运行中切换。`SkinCatalog.Skins` 列出内置和已导入的外观，`Find(id)` 根据保存的选择查找。

## 内置动画

E包、大肥鱼和马尔芙使用原有 8×11 基础图及独立四帧互动图，恢复此前的低帧播放时序；第四位预设伙伴小贝也采用低帧版本，包含“太极光环”专属动作。预设与导入伙伴均直接显示原画，不做帧间混合。窗口刷新与位移可以更频繁，但不等于每秒出现同等数量的新动作画面。v2 作者模板保留，不代表当前预设采用 24 FPS。

0.5.6 为四位内置伙伴提供原画参考重绘的四项技能、开心、拎起、普通落地及踉跄，每条 8 姿态、8 FPS，独立存于 `assets/companion-animations`；E包跳跃也已重绘。旧基础图集与未重绘动作保留。v1/v2 导入协议保持原有格式，缺少新素材的自定义外观继续普通落地和三项技能；同名自定义外观不会套用内置动作，不强制外观作者重做素材。详见 [互动扩展](interaction-extension.md)。

## 0.11.0-dev.3 完整角色包

带稳定 `id` 的完整包可直接导入 ZIP 或根 `pet.json`，并同时安装默认外观与 `holidays/catalog.json` 中的全部节日外观。五个官方创作源各含默认及十节日，共55套；发行文件采用 `DeskPet-Companion-{id}-0.11.0-dev.3.zip`。客户端仍按需下载完整角色包，不将55套动作全部嵌入主程序。

完整包统一限制：ZIP最多512 MiB、解压后与安装资源最多512 MiB、最多1024个ZIP条目（包括目录），根 `pet.json` 最多64 KiB，其他JSON最多1 MiB，单PNG最多25 MiB。每套外观的PNG合计仍最多256 MiB；默认动作帧数限制单独计算，不把所有节日帧相加。旧的无稳定ID v1/v2素材限制维持原有规则。

导入先预检所有条目、路径和解压总量，再逐图原生解码，复制到新目录后重读，最后原子发布指针。空间预检覆盖解压暂存、新安装副本及64 MiB余量；旧版本保持可用。后台导入显示进度窗口，可取消；发布指针之前的失败或取消保留旧角色。指针发布后的有效安装可由重启重新发现。

动作使用各自的 `frames/fps/loop`，不套用默认皮肤时长。摸头、戳身体和跳跃必须完整播放；跳跃图集已含起跳和落地，不叠加额外窗口跳跃。绘制与透明命中使用同一帧；缓存绑定角色来源及资源代次，绘制中的Avalonia图片持有引用直至该帧完成。

本地包声明官方角色ID不构成官方身份。`custom-pack:` 与 `official:` 的服装解锁及常驻选择分开保存；完整本地包可使用对应服装角色库，但不授予官方纪念卡信任。
