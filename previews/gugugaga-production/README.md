# 咕嘎首版素材验收

稳定 ID `gugugaga`；造型与头像母版见 `../gugugaga-v1/`。当前全部姿态由内置 imagegen 绘制，确定性处理复用 Pets 0.1.6 的完整连通域分组与检查，不创建 ChatGPT Work 宠物。

当前素材版本为 `0.9.3`，交付文件为 `gugugaga-HD-Skin-0.9.3.zip`；包文件名及内部说明均读取 `pet.json` 的 `pack_version`。

- 标准 v2：17 动作 × 8 帧、16 方向视线、480×520 预览。
- 双套：提起／拖动、落地、喂食、开心、小憩、摇摆、转圈、踉跄、顶肚跳；每套 8 帧、8 FPS。共 240 个有效姿态。
- `*-alt.gif` 对应第二套；不带 alt 是第一套。`*-contact.jpg` 是实际 192×208 大小的浅／深背景逐帧图。视线是顺时针从上开始的 16 方向，不是转身图。
- 生产源与精确提示保存在本地 `work/gugugaga-art/`；交付包的 `provenance.json` 保存采用源的哈希、精确提示、拆帧与统一变换参数。原始生成源不随 ZIP 再分发。
- 跨行寻找真实透明留白，再按连通域取出完整人物；同一组统一缩放、同一源行统一定位，保留起跳高度；没有复制帧、镜像左行或插帧凑数。
- 两套顶肚跳均保留低鳍、腹部前顶与起落。睡觉使用更低的整组高度，避免坐姿被撑大。戳戳素材重新编辑去掉悬浮强调符号。
- 人格仅用于普通聊天，未改工作提示词；未调用真实模型试聊或试听音色。动作来源及候选身份边界见动作参考文档。

重建：`python tools/prepare_gugugaga.py --build`，再执行 `python tools/package_gugugaga.py`。前者需要本地生产源、精确提示 JSON 及 Pets 0.1.6 脚本；后者仅需仓库中的最终素材。

ZIP 内根目录 `pet.json` 沿用标准 v2，并声明固定 ID、头像、人格、音色推荐及双套动作。新版直接导入 ZIP 即启用全部字段；同 ID 更新只展示一项并保留个人配置。旧引擎可解压后导入标准动作，但需升级一次才能使用完整功能。具体规则见 [完整角色包](../../docs/character-packs.md)。
