# DeskPet

[简体中文](../README.md) | [English](readme.en.md)

Run `桌面伙伴.exe`. Windows requires .NET Framework 4.8.
Keep the updater helper and configuration files alongside the application in both installed and portable editions.

- Settings, credentials, chat history, and imported skins are stored in the adjacent `data` folder. Keep a backup.
- See the [configuration guide](configuration-guide.md) for setup and the [daily use guide](daily-use.md) for everyday operations. These detailed guides are currently in Chinese.
- Choose the stable (`main`) or preview (`dev`) update channel in About. Preview builds may contain unfinished features.
- Changing channels never downgrades the application. If your preview version is newer than the latest stable version, the application waits for a higher stable version.
- Automatic updates and “Check and update” wait until it is safe, then show a five-second countdown. “Update and restart now” skips the countdown.
- Updates wait for tasks, drafts, and data to be saved rather than interrupting them.
- The interface follows your system language by default. Choose a language from the bottom-left avatar menu; saving refreshes the interface immediately and retains drafts, windows and running tasks. New requests use the new language; existing and custom content is preserved.
- See the [English changelog](changelog.en.md) or [Chinese changelog](../CHANGELOG.md) for version history.
- Character creation templates are a separate download. Use “Download creation template” in Settings, or find the `DeskPet-Skin-Template-v2` asset on [GitHub Releases](https://github.com/Eason4869/deskpet/releases).
- See the [skin format guide](skin-format.md) and [third-party notices](third-party-notices.md).

Ebao's default HD actions and avatar support offline startup. Other official companions download when first selected; you can also download or update all packs in Settings. Complete packs include the default outfit and published holiday outfits. Using a character does not require downloading a creation template.

- First-run setup places GitHub routing before character selection and an optional full official-pack download/update. Preparation continues while you proceed through or close the guide.

Companion material versions are independent of the application version. Verified identical packs are reused. Managed history becomes eligible after seven retirement days; current, recovery, active, unknown and legacy resources remain protected. Automatic post-install maintenance affects only managed companion history, preserving chat, relationships, personal images and custom packs.

- Chat through QQ, WeChat, Feishu, DingTalk or WeCom: see the [messaging channel guide](im-channels.md). No public IP is required; keep your computer online and DeskPet running.
