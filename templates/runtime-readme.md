# 桌面伙伴 DeskPet

[简体中文](README.md) | [English](docs/readme.en.md)

运行“桌面伙伴.exe”。Windows 需要 .NET Framework 4.8。
安装版和便携版都应保留同目录的更新助手和配置文件。

- 设置、密钥、聊天记录和导入外观保存在程序同目录的 data 文件夹，请保留备份。
- 首次配置见 [配置教程](docs/configuration-guide.md)，日常操作见 [使用说明](docs/daily-use.md)。
- “关于”页可选正式版（main）或预览版（dev）更新通道；预览版可能包含未稳定功能。
- 通道切换不会降级。若当前预览版本高于最新正式版，程序会等待更高的正式版本。
- 检查并更新、自动更新在安全空闲后保留 5 秒倒计时；点击“立即更新并重启”可跳过倒计时。
- 更新等待任务、草稿和数据保存完成，不会强制中断任务。
- 语言默认跟随系统；可在左下角头像菜单选择语言，保存后下次启动生效。
- 版本记录见 [更新日志](CHANGELOG.md)（[English](docs/changelog.en.md)）。
- 制作新角色所需完整模板独立下载：在设置中点击“下载制作模板”，或在
  [GitHub Release](https://github.com/Eason4869/deskpet/releases) 寻找 DeskPet-Skin-Template-v2 附件。
- 外观导入见 [外观说明](docs/skin-format.md)，第三方声明见 [许可说明](docs/third-party-notices.md)。

E包的完整素材已内置，可离线使用。其他官方伙伴首次选择时按需下载，也可在设置中“全量下载／更新”；完整角色包包含默认服装和已发布节日服装。使用角色不需要额外下载创作模板。
